# EFT 정서케어 트래커 — 설계 문서 (4주차 PRD)

- 작성일: 2026-07-21
- 만든 사람: 자인(허정우) · 스폰지클럽 2기 3조
- 과제: 4주차 — PRD 기획 및 구현 → 유저 피드백 → SNS 기록

---

## 0. 한 줄 요약

정서적 스트레스·화병 증상을 **매일 자가진단(0~4점)**하고, 그 자리에서 **EFT 자가치료 프로토콜**을 따라 감정을 다스린 뒤 **즉석 변화(NRS 0~10)**를 확인해, 변화 추이를 눈으로 보게 해주는 **정적 웹앱(localStorage 기반)** 프로토타입.

## 1. 배경과 문제 인식

한국 의료 문화는 병원 의존적이고 양방으로 편중되어 있어, 자연치유·셀프케어·홈케어 문화가 약하다. 이 프로젝트의 전체 비전은 학습 → 실천 → 커뮤니티 → 구매 → 진료연계 → 전국 네트워크로 이어지는 셀프케어 플랫폼이지만, **그 전체를 한 주에 만들 수는 없다.** 이번 4주차에서는 그중 **"실천(자가진단 + 습관기록)"** 한 조각만 떼어내, 소프트웨어로 직접 만졌을 때 가장 티가 나는 부분을 프로토타입으로 구현한다.

전체 비전에서 이 조각의 위치: **C-2 "실천" 단계** (전체 로드맵 1학습 → **2실천** → 3커뮤니티 → 4구매 → 5진료연계 → 6전국연계 중 2단계).

## 2. 주요 가치 (Value)

> **"내 감정 상태를 매일 스스로 체크하고, 그 자리에서 EFT로 다스린 뒤 변화를 눈으로 확인하는 습관."**

- 병원에 가지 않고도 지금 당장 시작할 수 있는 정서 셀프케어
- 막연한 "괜찮아졌겠지"가 아니라, **숫자로 남는 Before → After**로 효과를 체감
- 매일의 기록이 쌓여 **내 정서 추이 그래프**가 되어, 자기 상태를 객관적으로 인식

## 3. 페르소나 (Persona)

**주 타겟: 스폰지클럽 멤버 (약 100명) 같은, 자기관리에 익숙한 일반 성인**

- 정서적 스트레스·불안·긴장·화병 증상을 일상적으로 느끼지만, 그때마다 병원에 가지는 않음
- 자기관리·생산성 도구에 이미 익숙해서, 새로운 셀프케어 루틴을 붙이는 데 거부감이 적음
- 이번 4주차 과제 요건("실제 유저 2명 이상 피드백")과도 자연스럽게 연결되는 그룹

> 확장 타겟(이번 주 범위 밖): 병원 입원 중인 암환자(임상 데이터화 환경), 병원 유튜브 구독자(2.3만명).

## 4. 소구 방식 (Appeal)

**전문가 신뢰 중심.** 온보딩에서 만든 사람의 전문성을 앞세워 "이건 근거 있는 방법이다"라는 믿음을 먼저 준다.

- 17년차 한의사 · 암 한방병원장
- EFT / 정서 자가치료 프로토콜에 대한 임상 경험
- (심리검사 척도는 검증된 화병척도 기반임을 함께 표기)

## 5. 저작권·표현 관련 주의 (설계에 반영)

이 설계는 세 가지를 조심해서 우회한다.

1. **"마음침" 표현 → 사용하지 않음.** 마음침은 EFT + 사암침이 결합된 침법으로, 원 개발자(한의사 이정환 원장)의 동의가 필요할 수 있다(저작권 가능성). 대신 **오픈소스인 "EFT(Emotional Freedom Technique)"** 로만 브랜딩한다. 침 시술 부분(경혈지압)은 EFT 타점 두드리기로 대체한다.
2. **Beck 불안척도(BAI) · Beck 우울척도(BDI) → 사용하지 않음.** 상업 라이선스가 있는 심리검사 도구다. 앱에 문항을 그대로 넣지 않는다.
3. **화병척도 → 사용하되 출처 표기.** 권정혜·김종우 계열의 검증된 연구 척도(화병 성격 16문항 + 증상 15문항, 0~4점). 연구용 도구이므로 앱 내에 출처를 명시한다.

## 6. 기능 설계 (화면 구성)

정적 웹앱, 백엔드 없음, 데이터는 브라우저 `localStorage`에 저장. 1페이지 안에서 화면(뷰)을 전환하는 SPA 형태.

### 화면 1 — 온보딩 / 랜딩
- EFT가 무엇인지 짧은 설명 (침 없이, 타점을 두드려 감정을 다스리는 오픈소스 자가치료법)
- 만든 사람 프로필로 신뢰 소구 (17년차 한의사 · 암 한방병원장)
- "시작하기" 버튼 → 화면 2로

### 화면 2 — 오늘의 자가진단 (화병 증상 15문항, 0~4점)
- 화병 **증상 15문항**을 0~4점(전혀 그렇지 않다 ~ 완전히 그렇다)으로 응답
- 성향(trait) 지표인 **성격 16문항**은 매일 하기엔 부적합 → 온보딩 시 1회 또는 "가끔 하는 성향 체크"로 분리(이번 주 구현은 **선택사항**, 우선순위 낮음)
- 응답 완료 시 **오늘의 총점** 산출 후 저장, 화면 4(대시보드) 또는 화면 3(EFT 실천)으로 유도
- 척도 하단에 출처 표기

### 화면 2.5 — EFT 처음이신 분을 위한 안내
- EFT 타점 위치와 두드리는 법을 짧은 텍스트 + 간단한 그림/도식으로 안내
- "EFT를 이미 안다"를 선택하면 건너뛸 수 있음 (localStorage에 '안내 봤음' 저장 → 다음부터 자동 스킵)

### 화면 3 — EFT 실천 기록 (자가치료 프로토콜, 8단계)
기존 마음침 자가치료 프로토콜을 **EFT 버전**으로 그대로 따라가되, 감정 형상화·의식 집중 유도를 강조한다.

1. **상황·감정 적기** — 불쾌한 감정이 떠오르는 상황과 감정들을 입력
2. **가장 큰 감정 하나 선택** — 여러 감정 중 대표 감정 하나 (감정목록 참고 제공 가능)
3. **강도 체크 (NRS 0~10, before)** — 이 감정이 지금 얼마나 강한지 (SUD)
4. **감정 형상화** — 감정을 온도 · 촉감/질감 · 색깔 · 모양 · **크기** · **무게**로 구체화 (주관식 입력 + 일부 객관식 보조). *이 구체화 정도와 의식 집중이 효과에 큰 영향을 주므로, 안내 문구로 상상을 적극 유도한다.*
5. **몸의 위치** — 그 감정이 몸 어디에 있는지 (앞/뒤 인체 그림에서 탭으로 위치 선택, 또는 텍스트)
6. **호흡** — 감정이 있는 곳을 바라보며 깊은 호흡 3회 (타이머/안내 문구)
7. **EFT 타점 두드리기** — 타점 순서 안내를 보며 두드리기 (경혈지압 대체)
8. **재측정 (NRS 0~10, after)** — 처음 감정을 다시 느껴보고 강도 재측정 → **Before → After 변화가 한 화면에 남음**, 세션으로 저장

### 화면 4 — 변화 추이 대시보드
- **일일 화병 증상 총점 추이** 그래프 (날짜별)
- **EFT 세션별 Before → After NRS 변화** 목록/그래프 (그 자리에서 몇 점 내려갔는지)
- 연속 실천일수(스트릭) 표시
- 지난 세션의 감정·형상화 기록 리스트

## 8. 기술 스택 / 구현 방식

- **정적 단일 페이지 웹앱**: HTML + CSS + Vanilla JS (또는 가벼운 단일 파일). 빌드 도구 없이 브라우저에서 바로 열림.
- 그래프: 외부 CDN 대신 가벼운 인라인 방식(간단한 SVG/canvas) 또는 최소 라이브러리. 배포·오프라인 고려해 의존성 최소화.
- **데이터 저장**: `localStorage` (기기 로컬). 서버·DB·로그인 없음.
- **배포**: GitHub Pages 등 정적 호스팅으로 링크 공유 → 실제 유저 2명 이상에게 피드백 요청.
- 데이터가 기기별로만 저장된다는 한계가 있으나, PRD 검증용 프로토타입에는 충분. 서버/DB 확장은 다음 단계.

## 9. 이번 주 범위 (Scope) — YAGNI

**포함:**
- 화면 1, 2, 2.5, 3, 4
- 화병 증상 15문항 일일 자가진단 (0~4)
- EFT 8단계 프로토콜 + Before/After NRS
- 감정 형상화 입력 (위치·크기·형상·온도·무게·촉감)
- localStorage 저장 + 추이 대시보드

**제외(다음 단계):**
- 화병 성격 16문항 (선택사항, 우선순위 낮음 — 시간 남으면 온보딩 1회 체크로)
- 서버·DB·계정·다기기 동기화
- 커뮤니티·구매·진료연계 (전체 비전 3~6단계)
- 자석요법/파동패치 등 침 대체 물리 도구 연계

## 10. 성공 기준

- 스폰지클럽 멤버 등 실제 유저 2명 이상이 직접 써보고 피드백을 줄 수 있다.
- 한 세션에서 감정 강도(NRS)가 Before → After로 **눈에 보이게 기록**된다.
- 며칠 써보면 대시보드에 **내 정서 추이**가 그래프로 쌓인다.
- 4주차 과제 3요소(PRD·피드백·SNS 기록)를 채울 수 있는 결과물이 나온다.
