## 확정된 결정 (질의응답 결과)

1. **Lv.1 체간 6혈(중부·수부·전중·거궐·일월·대포)** — 사용자가 "동의 받았음/문제없음"으로 확인. 그대로 사용.
   - 단, README의 권리 관련 주장 문구는 삭제하고 사실 서술만 남긴다. 권리 표현은 사용자가 직접 정한다.
2. **회원가입** — 닉네임만 입력받아 localStorage에 저장(서버·계정 없음).
3. **미디어(이미지·영상·음악·외부링크)** — 자산 없음. 각 위치에 플레이스홀더만 배치하고, 파일/URL을 받으면 교체.
4. **화면 구조** — 자가진단과 EFT 실천은 **별도 메뉴로 유지**. 자가진단 기록을 실천에서 불러올 수 있게 연결.

## 변경 사항

### 전역
- 제목: "EFT 정서케어 트래커" → **"EFT 에너지 치유"**
- 온보딩에서 닉네임 입력

### 학습·동기부여 메뉴 (신규, 선택적 진입)
- 사용자 후기 인터뷰 (링크 자리)
- EFT 창시자 Gary Craig 소개 — TFT를 배웠으나 비싸고 복잡해 단순화, 인류를 위해 무료 배포 (링크 자리)
- 해외 사례·입증된 효과·학술적 근거 (링크 자리)
- EFT로 얻는 이익: 안 아프고·돈 안 들고·혼자 가능 / 화병, 우울증, 강박증, 공포증, ADHD, PTSD, 다이어트, 금연 / 긍정 심리·멘탈 강화·스포츠 기능 향상 / 삶의 주체성 확보
- 하지 않으면 입는 손해: 감정 손상 누적 → 임계점 초과 시 불면증·화병·자율신경실조증 등, 극단적으로 암까지
- 이 앱을 써야 하는 이유: 시공간 제약 없는 자가치유 / 전문가 1회 세션 10~30만원 vs 무료 / 커뮤니티 연계(링크 자리)

### 자가진단 (전면 개편)
- **화병 15문항 전부 제거** (매일 반복할 필요 없음)
- EFT 1·2단계(상황·감정)를 자가진단으로 이동
- 부정 감정을 카테고리별 객관식으로 제시 + 없으면 주관식 직접 입력

### EFT 실천 (12단계로 확장·재배열)
1. 어떤 상황인가요? — "최근 감정이 불편하거나 힘들었던 상황 혹은 그렇게 만든 사람을 구체적으로 떠올려 보세요." 예시 확대. "드나요"→"들었나요"
2. 가장 큰 감정 하나 선택 (카테고리별 목록 활용)
3. 강도 체크 (NRS 0~10, before)
4. **그 느낌은 몸의 어디에 있나요?** (형상화보다 **앞**으로). 예시: 가슴 중앙, 명치, 복부, 뒷목, 어깨, 머리
5. 감정을 몸의 느낌으로 그려보세요 — "구체적이고 생생하게 상상할수록 효과가 커집니다. 다 채우지 않고, 잘 느껴지는 항목만 적으시면 됩니다."
   순서: **크기 → 무게 → 온도 → 색깔 → 모양 → 촉감·질감**
6. 호흡하기 — "+의식을 집중할수록 효과가 배가됩니다."
7. **수용확언 (신규)** — "나는 지금 비록 ~~하지만, 이런 내 자신을 온전히 받아들이고 사랑합니다." 손날(후계혈) 태핑. 미디어 자리. 신체 증상도 가능하나 처음엔 감정 영역 권장.
8. 타점 두드리기 **Lv.1** — 체간 6혈, **각 30회씩**, "그 감정과 에너지에 집중". 음악·위치 이미지·시연 영상(두드리기/문지르기) 자리
9. **뇌조율 과정 (신규)** — 중저혈(손등) 두드리며 9동작. 미디어 자리
10. **심호흡 2번 (신규)**
11. **재평가** — after NRS + 50% 기준 + 장면 변화(작아짐·멀어짐·흐릿) + 관점 전환 안내
12. **효과 미비 시 해결법 (신규)** — 30% 미만 시 재시도 / 주 감정 변경 / Lv.2~4 시도 / 하루이틀 후 재시도 / 전문가 권유

### 레벨 체계 (신규)
- **Lv.1** 체간 6혈: 중부, 수부, 전중, 거궐, 일월, 대포 (양측)
- **Lv.2** 머리·얼굴·체간: 손날점(후계), 정수리(백회), 눈썹(찬죽), 눈 옆(동자료), 눈 밑(승읍), 코 밑(인중), 턱(승장), 쇄골(결분), 겨드랑이 아래(대포)
- **Lv.3** 손가락·손등·손목: 엄지(소상), 검지(상양), 중지(중충), 약지(관충), 소지(소충·소택), 손등(중저), 손목(내관)
- **Lv.4** 긍정 강조 모델: (−)를 줄이는 게 아니라 (+)를 늘리는 과정. 문제가 완전히 해결된 상태의 감정·에너지 형상을 상상하며 Lv.1~3 태핑 반복
