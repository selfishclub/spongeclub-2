## D1. 여행 준비 앱으로 전환 (인사이트 ①)

- 지참 리스트 → **여행 준비 리스트**로 확장
- 섹션 구조: **의류(자동 생성)** / 신발 / 서류·결제 / 전자기기 / 상비약 / 기타
- 옷차림 추천은 '의류' 섹션을 자동으로 채우는 엔진 역할
- 사용자 직접 입력 시 섹션 선택 가능 (현재는 전부 '기타'로 떨어짐)

## D2. 단위 · 기준점 (인사이트 ②)

**결정: 거주지·옷장 보유 여부는 묻지 않는다.** 온도 단위만 다룬다.

- 기본값: 브라우저 로케일/타임존으로 **자동 판정** (US·BS·KY·LR 등 → °F, 그 외 → °C)
- 사용자가 **수동 변경 가능** (설정 토글)
- 비교 기준 도시: `REFERENCE_CITY = "서울"` 하드코딩 제거 → **접속 위치 기준 자동 판정**
- 별도 입력 폼 없음. 감지 결과만 표시하고 바꿀 수 있게 함

## D3. 여행 목적 세분화 (인사이트 ③)

상위 3유형 유지 + 하위 **다중선택 목적 칩**(한 여행에 2~3개 선택 상정)

| 상위 유형 | 목적 칩 | 옷차림 반영 |
|---|---|---|
| **도시형** | 미식 | 좌식 대응, 냄새 배는 소재 회피, 편한 허리 |
| | 감성·기록 | 사진 톤 고려, 무채 배경 + 포인트 컬러 |
| | 쇼핑 | 탈착 쉬운 겉옷, 가벼운 신발 |
| | 전시·문화 | 실내외 온도차 → 얇은 레이어 |
| | 야경·나이트 | 일교차 대응 겉옷 |
| **자연·액티비티형** | 트레킹·등산 | 기능성 상의, 방풍, 접지력 |
| | 숲길·산책 | 트레킹화 과함 → 편한 운동화 |
| | 해변·물놀이 | 자외선 차단, 속건, 샌들 |
| | 캠핑 | 야간 기온 급강하 대응 |
| **혼합·휴양형** | 온천·스파 | 탈착 간편, 여벌 속옷 |
| | 리조트·호캉스 | 실내 냉방 대비 얇은 겉옷 |
| | 로컬 체험 | 활동성 + 예의 갖춘 선 |
| | 격식·이벤트 | 재킷·구두 포인트 |

## D4. 1인용 유지 + 성별 · 저장 리스트 (인사이트 ④ + ⑥)

- **동행 기능 만들지 않음.** 앱은 1인 기준 유지
- **성별 입력 추가** (남 / 여 / 선택 안 함) → 추천 아이템 풀 분기
- **나이대는 받지 않음** — 스타일 프로필이 그 역할을 대신함
- **가족 여행 대응 = 저장 리스트로 해결**
  - 검색 결과를 저장 → 목록으로 표시
  - 아이 기준으로 한 번 더 검색해 별도 저장
  - **저장 항목 삭제 가능**
- 저장 리스트는 `localStorage` 영속 → 인사이트 ⑥의 "닫으면 사라짐" 문제 동시 해결
- 남는 건 **[복사] 버튼 하나** (텍스트로 내보내기)

## D5. 날짜 비교 (인사이트 ⑤)

- 결함이 아니라 개선 기회. 우선순위 후순위
- 출발일 입력 아래 **주차별 기온 스트립** 표시 → 클릭하면 날짜 자동 입력
- 구현 비용: 해당 월 전체 10년 평균 조회 **API 호출 1회 추가**

```
 3월 4주   9°/1°   강수 20%
 4월 1주  14°/5°   강수 30%   ← 클릭 시 날짜 입력
 4월 2주  17°/8°   강수 35%
```

## D6. 언어 설정 (인사이트 ⑦)

- **언어 설정 기능 추가** (한국어 / English), 기본값은 브라우저 언어 자동 감지
- 레퍼런스 검색어를 **설정 언어로 자동 생성**
  - ko → `경주 여행룩`, `#경주여행룩`
  - en → `Gyeongju travel outfit spring layered`
- 핀터레스트·인스타 미사용자는 **구글 이미지 검색**으로 커버 (현재도 제공 중)
- 연령별 채널 분기는 하지 않음

## 반영하지 않기로 한 것

| 항목 | 사유 |
|---|---|
| 거주지 입력 폼 | 자동 감지로 충분, 입력 단계 증가 |
| 사계절 옷장 보유 확인 | 과한 질문 |
| 동행 추가 기능 | 저장 리스트로 대체 |
| 나이대 입력 | 스타일 프로필이 대신함 |
| 연령별 레퍼런스 채널 분기 | 구글 검색으로 커버됨 |
| 내보내기 CSV·카톡 공유 | 저장 리스트 + 복사 버튼으로 축소 |
