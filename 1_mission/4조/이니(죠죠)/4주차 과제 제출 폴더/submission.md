# 4주차 — 기획·구현 → 검증 → 기록 🧪

> 3주차까지는 "내 삶을 돕는" 개인 OS였다면, 4주차는 **실제 유저가 쓰는 프로덕트** 관점으로 전환.
> 흐름은 기획·구현 → 검증(피드백) → 기록. 세 과제를 그 순서로 채웠다.

<br>

## 🎯 과제 1. PRD 기획 및 구현

> 주요 가치 · 페르소나 · 소구 방식을 담은 PRD → 구현까지

<br>

### 💎 주요 가치 — 나루터가 지키는 5가지

| # | 가치 | 뜻 |
|---|------|----|
| 1 | 날 것 우선 | 완성해서 주지 않아도 됨. 던지면 정리는 시스템이 한다 |
| 2 | 한 줄씩 (0→100 금지) | 완벽하게 시작 안 함. 불편할 때마다 한 줄씩 자란다 |
| 3 | Self / External 안 섞기 | 내 생각과 외부 자료를 분리해 신뢰를 지킨다 |
| 4 | 과정이 자산 | 결과 자랑이 아니라 삽질·극복이 콘텐츠 (AI가 못 흉내내는 것) |
| 5 | 발행은 사람이 | 자동화하되 최종 결정·검수는 무조건 사람 |

<br>

### 👤 페르소나 — 타깃 유저

- **1호 유저 = 이니(나)** — 비개발자, 콘텐츠 기획 → AI PM 전환 중. *"배운 게 휘발된다"* 는 고민에서 출발

**확장 3유형**

| 유형 | 상태 | 어떤 고민 |
|------|------|-----------|
| ① 쌓이기만 하는 사람 | 배운 게 자산화가 안 됨 | 강의·자료는 쌓는데 내 것이 안 됨 |
| ② 만들고 싶은 비개발자 | AI로 뭘 만들고 싶은데 개발을 모름 | 어디서 시작할지 막막함 |
| ③ 전환 중인 사람 | 커리어 전환 중, 포폴 재료가 급함 | 보여줄 결과물이 없음 |

<br>

### 🗣️ 소구 방식 — 가치를 "그 사람의 언어로 번역"

> 수업 핵심: 가치를 그대로 말하지 않고, 그 사람의 언어로 옮긴다.

| 내부 가치 | 유저에게 하는 말 |
|-----------|------------------|
| raw-only | "정리 안 해도 돼요, 그냥 던지세요" |
| 0→100 금지 | "완벽하게 시작 안 해도 돼요" |
| 과정이 자산 | "삽질까지 다 포트폴리오가 됩니다" |

<br>

### ⚙️ 구현한 것 (증거)

| 영역 | 만든 것 |
|------|---------|
| 🖥️ 나루터 뉴버전 (로컬) | 이번 주 실제로 업데이트한 신버전 대시보드 (성장 대시보드·소화 흐름·달력 등). *구버전 공개판: https://iny-naru.vercel.app* |
| 🛶 조직 | 세 식구(나루·여울·너울) 페르소나 + 위임·취합·보고 구조 |
| 🤖 자동발송 3종 | 아침·저녁 하루 루프 + 주간 트렌드 루프 |
| 🌌 소화 흐름 | 성운일지 카드 안에서 여울과 대화하며 자료를 개념으로 소화 |
| 📈 성장 대시보드 | 기록 탭 상단 "실패를 개선으로" 우상향 곡선 (AI PM 포폴용) |
| 📤 발행 파이프 | 스레드·인스타 실발행까지 (초안→이미지→게시) |

## 🗣 과제 2. 유저 피드백 받기

> 이번 주 검증은 **가상 페르소나 피드백**으로 진행했다. (실제 유저 인터뷰는 다음 단계로 — 아래 "아직 확인 못한 것".)
> 지난주 배운 **가상 고객 피드백 스킬**(NVIDIA 네모트론 한국 700만 페르소나 기반)로, 타깃 패널을 뽑아 세 모드로 부딪혔다.

<br>

### 🤖 가상 페르소나 피드백

> 스킬(`virtual-customer-feedback`)로 **NVIDIA 네모트론 한국 페르소나** 팩에서 타깃(2030 커리어 전환·자기계발러) 패널을 뽑아 세 모드로 부딪혔다. *가상 피드백은 실제 검증의 전 단계다.*

**만난 가상 고객 4명** — 김재성(22·취준 영상편집)·최동현(33·경찰·블로그 운영)·황혜란(33·경리·효율형)·김세원(34·1인 스마트스토어)

<br>

**① 패널 인터뷰 — "쓸까, 왜 안 쓸까"**

공통 거절 이유 (= 최우선 개선 포인트)

| 순위 | 거절 이유 | 누가 |
|---|---|---|
| 1 | 세팅 진입장벽 (터미널·설치) | 재성·세원 (혜란 간접) |
| 2 | 프라이버시 — 내 기록을 AI가 다 읽는 불안 | 동현 |
| 3 | 기존 도구(노션·블로그·엑셀) 이관 이유 부재 | 재성·동현·혜란 |
| 4 | 자동 발행 신뢰 (검수 없이 나갈까 봐) | 동현 |

<br>

**② 기능 메리트 평가 — 어느 기능이 진짜 쓸 이유가 되나**

| 순위 | 기능 | 반응 |
|---|---|---|
| 1위 | 던지면 소화 (자료→개념 정리) | 나루터의 본질, 전원 관심 |
| 2위 | 항해일지(소화→콘텐츠) + 성장 대시보드 | 콘텐츠·포폴 니즈 있는 층에 강함, 타깃과 일치 |
| 3위 | 자동 체크인 (먼저 말 걸기) | 갈림 — 혼자 하면 +, 루틴형엔 알림 피로 → 온·오프 필수 |
| 낮음 | 개념 별자리 · 세 식구 캐릭터 | 예쁘지만 "쓸 이유"보단 복잡도↑ → 곁가지로 |

→ 진짜 메리트는 **지식 자산화 파이프(던지기→소화→콘텐츠→성장기록)** 에 몰려 있음.

<br>

**③ 온보딩 워크스루 — 신 구조(배포+로그인+내 데이터만 연결) 기준**

| 단계 | 저디지털(76세) | 타깃(22세) |
|---|---|---|
| 웹 접속 | 통과 | 통과 |
| 로그인 | 조건부 통과 | 통과 |
| 내 데이터 연결 | "노션이 뭐요" → 이탈 | "권한 화면이 안전한가?" 머뭇 → 통과 |
| 첫 자료 던지기·소화 | — | 통과 → **완주** |

→ Vercel 배포+로그인 구조가 이전(터미널·git) 이탈을 풂. 타깃은 완주. 남은 머뭇 = **데이터 연결의 프라이버시 안심**.

<br>

> 🧽 가장 의외였던 반응 — 최동현: *"정리 자동화는 솔깃한데, 내 기록을 AI가 다 읽는 게 제일 꺼려져요."* 기능보다 프라이버시가 첫 거절.

<br>

### 💡 피드백에서 알게 된 것 — 개선 로드맵

세 모드가 한 곳을 가리켰다: **진짜 벽은 기능이 아니라 ①진입장벽과 ②첫인상(가치가 안 보임)**.

| 우선순위 | 개선 | 근거 (어느 모드) |
|---|---|---|
| **P1 진입장벽 제거** | 탭 정리 → Vercel 배포 → 로그인 → 내 데이터만 연결 (터미널·git 없이) | 패널 거절 1위 · 온보딩 |
| **P2 첫 화면이 가치를 먼저** | 배포판 첫 화면 = "완료율·체크"가 아니라 "던지면 → 소화 → 콘텐츠". 은유(항해일지·씨앗)에 쉬운 설명 병기 | 기능 평가 · 5초 오인 |
| **P3 핵심 파이프 전면 / 곁가지 옵션** | 던지면 소화·항해일지·성장은 메인 동선, 별자리·세 식구는 옵션, 자동 체크인 온·오프 | 기능 메리트 랭킹 |
| **P4 프라이버시 안심** | "내 저장 + 발행은 사람 승인"을 소구 메시지로 + 데이터 연결 단계에 "무엇을 읽고 안 읽는지" 안내 | 패널 2위 · 온보딩 머뭇 |

**아직 확인 못한 것 (실제 고객에게 검증)** — "배포판(세팅 없는 형태)이면 진짜 쓸 것인가?" / 데이터 연결 안심 문구가 불안을 실제로 없애는가?
