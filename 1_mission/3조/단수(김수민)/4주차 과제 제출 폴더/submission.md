## 🎯 과제 1. PRD 기획 및 구현
> 주요 가치 · 페르소나 · 소구 방식을 담은 PRD → 구현까지

- **주요 가치:**
  주목습관은 본업과 자기 작업을 병행하는 사람들이 동료와 **주 단위 목표**를 이어가는 커뮤니티다. 이번 MVP의 주요 가치는 운영자가 매주 반복하던 인증 확인, 현황 정리, 예외 처리와 공유 작업을 줄이는 것이다.

  제품의 한 문장 약속:
  > 정리 말고, 동료를 주목하는 데 시간을 쓴다.

- **페르소나:**
  - **1인 커뮤니티 운영자** (Discord에서 챌린지를 혼자 운영)
    - 여러 채널의 사진 인증을 직접 확인
    - 참여자별 목표와 진행률을 수작업으로 정리
    - 늦은 인증이나 중복 인증 같은 예외를 판단
    - 운영 설정을 바꿀 때마다 개발자나 AI에게 요청하고 싶지 않음
  - **참여자**: 본업을 병행하면서 자기 작업을 지속하고 싶은 크리에이터. Discord에서 평소처럼 인증하고, 복잡한 관리 기능은 운영자 화면에 모음

- **소구 방식:**
  기능 수보다 **운영자가 돌려받는 시간**을 보여주는 방식으로 잡았다.
  - Discord의 익숙한 인증 경험은 유지
  - 일별 스레드를 주간 스레드로 바꿔 기록이 흩어지지 않게 함
  - 운영자가 기간, 멤버, 목표, 인증 시간, 이모지와 예외를 직접 관리
  - 자동화가 애매한 판단까지 대신하지 않고, 최종 결정은 운영자에게 남김

- **구현한 것 (링크·스크린샷 — 이미지는 `이미지첨부/` 폴더에):**

  **구현 과정**
  1. 기존 Discord 운영 기록과 Obsidian 문서를 읽어 PRD를 정리
  2. Hermes로 작업을 관리하고 Claude Code Opus를 구현 실행자로 사용
  3. 첫 MVP를 만든 뒤 실제 Discord에서 시험 — 처음 선택한 분리형 현황 메시지와 스레드가 직관적이지 않아, 부모 현황 메시지에서 바로 주간 스레드가 시작되는 구조로 재설계
  4. 제품의 중심을 단순한 봇이 아니라 운영자가 직접 쓰는 **Admin OS**로 확장
  5. 테스트 중 동시에 두 빌드가 실행되어 E2E가 실패한 적이 있었음 — 동시 실행 충돌을 확인한 뒤 단독으로 재검증

  **구현한 기능 (Discord 주간 인증 봇)**
  - 부모 현황 메시지와 연결된 주간 스레드
  - 참여자 자동 멘션과 스레드 자동 노출
  - 사진 인증, 하루 1회 인정, 늦음·중복·수동 인정 처리
  - 월~일 진행표와 누적 횟수 자동 갱신
  - 챌린지 기간, 멤버, 개인 목표, 인증 시간, 이모지와 문구 설정
  - 현재 주차 운영 콘솔과 Discord 출력 미리보기
  - 예외 검토와 감사 기록
  - 주간 리포트, 승인·게시 흐름, 참여자 대시보드

  Next.js, TypeScript, SQLite, discord.js로 구현. 단위·통합 테스트 211개와 브라우저 E2E 6개를 통과했고, 프로덕션 빌드와 실제 브라우저 화면도 확인함. (코드 저장소와 실제 Discord 링크는 운영 정보 보호를 위해 비공개)

  **결과**
  운영자는 AI나 코드 수정 없이 어드민에서 주간 운영 설정과 예외를 직접 처리할 수 있게 됨. 참여자는 기존처럼 Discord에서 사진을 올리면 되고, 봇은 같은 주간 현황 메시지를 계속 갱신함. 실제 운영 전환은 별도 검증과 백업을 거쳐 진행할 예정.
