## 🎯 과제 1. 구현, 그 다음의 것

![과제 1 안내](https://github.com/selfishclub/spongeclub-2/raw/main/_meta/week5/mission1.png)

> 만드는 건 끝났는데 — 그 다음이 진짜 시작이에요 (답이 안 나와 있어도 OK, 고민을 꺼내놓는 것 자체가 과제)
- **지금 걸려 있는 고민 하나:** `/결정` 스킬 없이도 그냥 클로드 대화창에 잘 물어보면 똑같이 되는 거 아닌가 — "불필요한 서비스 구현"이라는 의심
- **그게 왜 고민인지 (무엇이 걸리는지):** GROW·소크라테스·프리모템 같은 프레임워크는 그때그때 프롬프트로 물어봐도 되는 거라서, "질문 잘 던지는 기술"만 파는 거면 스킬이 굳이 있을 이유가 약해짐
- **어떻게 풀어볼 생각인지:** 챗창 혼자서는 못 만드는 부분에 집중하기로 함 — 쌓인 결정 기록(decision_log) 위에 "패턴 분석"을 얹어서, N번째 결정마다 "이번에도 또 이 지점에서 막히네요"처럼 기록이 쌓여야만 가능한 걸 다음 버전(v4)의 핵심 가치로 삼기로 함
- **필요한 게 있다면 무엇인지:** 패턴을 뽑으려면 결정 기록이 더 쌓여야 하고, "패턴"을 뭘로 정의할지부터(반복되는 결정 유형인지 / 반복되는 회피 패턴인지 / 반복되는 결론인지) 설계가 필요함

## 🏁 과제 2. 구현 마무리 + 실제 유저 피드백 받기

![과제 2 안내](https://github.com/selfishclub/spongeclub-2/raw/main/_meta/week5/mission2.png)

> 시작할 때 "이번엔 이건 꼭 만들겠다" 했던 것 — 지금 어디까지 왔나요? (스폰지클럽 내 유저피드백 모집 가능)
- **최종 완성한 것 (지금 어디까지):** v3(반영 → GROW 흐름 → 유형별 프레임워크 → 결론 카드 → 기록 저장/삭제)까지 완성. 이후 추가 개발은 없었고, 이번 주 고민(과제1)이 다음 버전 방향이 됨
- **🚀 실제 배포 URL:** 없음 — 로컬 Claude Code 스킬로만 사용 중
- **결과물 (링크·스크린샷 — 이미지는 `이미지첨부/` 폴더에):** 배포되지 않은 로컬 스킬이라 스크린샷은 아직 없음
- **받은 유저 피드백:** 아직 못 받음 — 로컬 스킬이라 실사용자를 만나려면 노트북을 들고 직접 가야 하는 물리적 제약이 있어서 진행하지 못함

## 📣 과제 3. SNS에 남기기

![과제 3 안내](https://github.com/selfishclub/spongeclub-2/raw/main/_meta/week5/mission3.png)

> 구현했던 것들 + 그 다음 단계에 대한 생각 (아끼면 아무 일도 안 일어나요 — 꺼내놓는 순간 가장 많이 남아요)
- **구현했던 것들 (무엇을 / 어떻게 굴러가는지 / 뭐가 달라졌는지):** 고민을 결정으로 바꿔주는 `/결정` 스킬. GROW로 흐름을 잡고, 결정 유형별로 다른 프레임워크(소크라테스식 질문·프리모템·아이젠하워)를 붙이고, 결론 카드 한 장으로 닫아준다. 결정 기록도 쌓여서 나중에 이어서 대화할 수 있게 됨
- **다음 단계 생각 (뭘 더 하고 싶은지 / 남은 것 / 어디로):** "이거 그냥 클로드한테 잘 물어보면 되는 거 아닌가"라는 의심을 계기로, 다음엔 쌓인 기록 위에 패턴을 읽어주는 기능(v4)을 얹어보고 싶음. 배포와 실사용자 피드백은 여전히 남은 숙제
