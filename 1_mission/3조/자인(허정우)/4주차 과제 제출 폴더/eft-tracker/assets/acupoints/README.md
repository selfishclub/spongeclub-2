# 혈자리 위치 이미지 넣는 곳

각 혈자리의 "혈자리 위치" 버튼을 누르면 이 폴더의 이미지를 찾아 보여줍니다.
**권리가 있는(또는 직접 만든) 이미지**를 아래 파일명으로 이 폴더에 넣으면 자동 연결됩니다.
파일이 없는 혈자리는 저작권 안전한 도식(SVG)이 대신 표시됩니다.

- 형식: `.jpg` (파일명은 아래 슬러그와 정확히 일치해야 함)

## 파일명 목록

### 태핑 1단계 (체간)
- `중부.jpg`, `수부.jpg`, `전중.jpg`, `거궐.jpg`, `일월.jpg`, `대포.jpg`

### 태핑 2단계 (머리·얼굴)
- `후계.jpg`, `백회.jpg`, `찬죽.jpg`, `동자료.jpg`, `승읍.jpg`, `인중.jpg`, `승장.jpg`, `결분.jpg`, `대포.jpg`

### 태핑 3단계 (손)
- `소상.jpg`, `상양.jpg`, `중충.jpg`, `관충.jpg`, `소충소택.jpg`, `중저.jpg`, `내관.jpg`

> 참고: 인터넷의 경혈 해부학 이미지는 대부분 교재·사이트의 저작권 자료이므로,
> 권리 확인 없이 그대로 넣지 마세요.
