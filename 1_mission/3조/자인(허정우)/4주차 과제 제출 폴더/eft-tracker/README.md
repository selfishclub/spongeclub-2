# EFT 에너지 치유

힘들었던 상황과 감정을 자가진단하고, EFT 12단계를 따라 다스린 뒤
전후 변화(NRS 0~10)를 기록·추적하는 정적 웹앱 프로토타입. 스폰지클럽 2기 4주차 과제.

- 만든 사람: 자인(허정우) · 3조
- 데이터는 브라우저 localStorage에만 저장(서버·계정 없음, 닉네임도 이 기기에만 저장)
- 외부 라이브러리 없음(순수 HTML/CSS/JS, 그래프는 인라인 SVG)

## 로컬 실행

ES 모듈을 쓰므로 `file://`이 아니라 로컬 서버로 열어야 합니다.

```
cd eft-tracker
node ../../../../../.claude/static-server.mjs . 8137
# 브라우저에서 http://localhost:8137
```

## 테스트

```
cd eft-tracker
node --test
```

## 화면

1. **온보딩** — EFT 소개 + 닉네임 입력 + 만든 사람 소개
2. **알아보기** — Gary Craig 창시 배경, 학술적 근거, 얻는 이익, 하지 않으면 입는 손해, 이 앱을 써야 하는 이유
3. **자가진단** — 힘들었던 상황 + 감정 선택(11개 카테고리 118개 + 직접 입력)
4. **EFT 안내** — 처음 사용자용 기본 안내
5. **EFT 실천 (12단계)** — 상황 → 대표감정 → 강도(before) → 몸의 위치 → 형상화(크기·무게·온도·색깔·모양·촉감) → 호흡 → 수용확언 → 타점 Lv.1 → 뇌조율 → 심호흡 → 재평가 → 효과 미비 시 해결법
6. **타점 레벨** — Lv.1(체간) / Lv.2(머리·얼굴) / Lv.3(손) / Lv.4(긍정 강조)
7. **대시보드** — EFT 전후 변화 추이, 최근 자가진단, 연속 실천일수

## 아직 채워지지 않은 것

이미지·영상·음악과 외부 링크(유튜브 사례, 커뮤니티 등)는 자리만 잡아둔 상태입니다.
화면에 "자료 준비 중"으로 표시되며, 자산이나 URL이 준비되면 그 자리를 교체하면 됩니다.

- 후계혈 두드리기 시연, 타점 위치 안내, 두드리기·문지르기 영상
- 뇌조율 동작 영상, 배경 음악
- 후기 인터뷰·학술 자료·커뮤니티 링크

## 참고

- EFT(Emotional Freedom Technique)는 Gary Craig가 무료로 공개한 기법입니다.
- Lv.1 체간 타점 및 Lv.2~3 타점은 한의학 혈자리 명칭을 사용합니다.
- 본 도구는 의료 진단·치료를 대체하지 않습니다.
