# EFT 정서케어 트래커

화병 증상 자가진단(0~4)과 EFT 8단계 자가치료(Before/After NRS 0~10)를 기록하고
변화 추이를 보여주는 정적 웹앱 프로토타입. 스폰지클럽 2기 4주차 과제.

- 만든 사람: 자인(허정우) · 3조
- 데이터는 브라우저 localStorage에만 저장(서버·계정 없음)
- 외부 라이브러리 없음(순수 HTML/CSS/JS, 그래프는 인라인 SVG)

## 로컬 실행

ES 모듈을 쓰므로 `file://`이 아니라 로컬 서버로 열어야 합니다.

```
cd eft-tracker
python -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 테스트

```
cd eft-tracker
node --test
```

## 화면

1. 온보딩 — EFT 소개 + 만든 사람(전문가) 소개
2. 자가진단 — 화병 증상 15문항(0~4)
3. EFT 안내 — 처음 사용자용 타점 안내
4. EFT 실천 — 8단계(상황→대표감정→강도 before→형상화→몸 위치→호흡→타점→강도 after)
5. 대시보드 — 총점 추이, EFT 전후 변화, 연속 실천일수

## 참고·저작권

- 화병 증상 문항 출처: 권정혜·김종우, 화병척도
- "마음침" 표현은 원 개발자 저작권 이슈로 사용하지 않고, 오픈소스인 EFT로만 구성
- Beck 척도(BAI/BDI)는 상업 라이선스 문제로 미사용
- 본 도구는 의료 진단·치료를 대체하지 않습니다.
