# 4주차 — 기획·구현 → 검증 → 기록 🧪

## 🎯 과제 1. PRD 기획 및 구현

> 주요 가치 · 페르소나 · 소구 방식을 담은 PRD → 구현까지

**제품: 워크숍 잉글리시 OS (Workshop English OS)** — v2.0
**한 줄 정의:** "기업 팀빌딩 워크숍을 영어로 진행해야 하는 강사를 위한, **내 강의 대본으로 리허설하는** 영어 훈련 OS"

**배경:** 기업 교육을 계속 한국어로 준비해 왔는데, 글로벌 기업 출강이 늘면서 청중에 외국인 임직원이 많아졌다. 시중 영어앱을 깔아봐도 "공항에서 커피 주문하기"를 연습할 시간에 나는 **내일 워크숍 오프닝 멘트**를 연습해야 했다. 그래서 인기 영어회화 서비스 4곳을 시장조사해 학습 원리만 추출하고, 콘텐츠는 전부 "진행자의 말"로 채웠다.

- **주요 가치 (시장조사 → 설계 원리):**

  | 벤치마킹 | 가져온 원리 | 이 OS의 구현 |
  | --- | --- | --- |
  | 스픽 | 말하기 우선 학습 | 오늘의 훈련: 원어민 발음 듣기 → 한국어만 보고 소리 내어 말하기 2단계 |
  | 말해보카 | 망각곡선 복습 + 게임화 | SRS 자동 복습(1→3→7→14→30일), 스트릭, 레벨 5단계 |
  | 링글 | 1:1 교정 피드백 | AI 코치 프롬프트 5종 — 한→영 대본 변환·롤플레이·교정·표현확장·Q&A (챗봇 붙여넣기 방식, 서버 API 키 없음) |
  | ELSA | 발음 훈련 | Web Speech API로 말하면 단어 단위 채점, 놓친 단어 표시 |

  여기에 상용 앱이 못 하는 것 하나를 얹었다: **한국어 강의 대본 → 무대용 영어 변환 → "나의 시나리오" 등록 → 문장별 리허설·채점**. 남이 만든 상황이 아니라 다음 주 내 강의로 연습하는 루프다.

- **페르소나:**
  - ① **나(대표강사)** — 글로벌 기업 워크숍 수주 증가, 영어 중급 / "오프닝~클로징 흐름이 입에서 저절로 나와야 한다"
  - ② **파트너 강사(강사양성과정 훈련생)** — 영어 수준·기기 제각각 / "내 분야 대본으로 연습하고, 폰을 바꿔도 기록이 남아야 한다"
  - ③ **트레이너(관리자로서의 나)** — 파트너 훈련을 과정 커리큘럼으로 관리 / "누가 매일 하는지 한 화면에서 봐야 한다"

- **소구 방식:**
  - **훅**: "스픽으로 커피는 주문해도, 워크숍은 진행 못 합니다"
  - **서사**: 범용 영어앱과 경쟁하지 않는다 — **"강사의 무대 영어 리허설 + 양성과정 트레이닝 관리"**라는 초니치. 강사양성과정에 번들하면 과정 자체의 부가가치가 된다
  - **증명**: 라이브 데모 + 가상 유저 실사용 검증(과제 2)

- **구현한 것 (링크·스크린샷 — 이미지는 `이미지첨부/` 폴더에):**
  - 🔗 **라이브: https://english-os-zeta.vercel.app** (Next.js + Vercel)
  - **5개 탭**: 오늘의 훈련(SRS+말하기 채점) / 표현 라이브러리(워크숍 진행 흐름 그대로 10개 카테고리 108표현, 문장마다 한국어 뜻+뉘앙스 팁) / 시나리오 리허설(풀 시나리오 32문장·L.A.D 미션 브리핑 24문장·돌발상황 대응 16문장 + 나의 시나리오) / AI 코치(프롬프트 5종) / 나의 진도(스트릭·레벨·리허설 진도)
  - **다인 사용**: 프로필(이름·분야·레벨이 AI 코치 프롬프트에 자동 반영) + 커스텀 시나리오 공유 링크(`#share=` URL, 서버 불필요) + 기수코드+이메일 서버 동기화(Vercel Blob, 훈련 완료 시 자동 백업) + **트레이너 대시보드**(`/trainer` — 파트너별 스트릭·마스터 표현·리허설 진도·마지막 백업을 한 표로)

## 🗣 과제 2. 유저 피드백 받기

> 실제 2명 이상 + 플러스 알파로 가상 페르소나

- **실제 유저 피드백 (2명 이상):** 아직 미진행 — 이 OS의 실제 유저(파트너 강사)는 다음 강사양성과정 기수에 합류하므로, 그때 실사용 피드백을 받을 예정. 이번 주는 가상 페르소나 시뮬레이션을 "실제 유저에 최대한 가깝게" 만드는 데 집중했다.

- **가상 페르소나 피드백 (네모트론 페르소나 2명):**

  **방법** — "그럴듯한 상상 인물"이 아니라 실데이터에서 뽑았다:
  1. NVIDIA 공개 데이터셋 **Nemotron-Personas-Korea**(한국 통계청 인구분포 62개 변수 기반 합성 페르소나 600만 건)에서 API로 600건 수집 → 직업·서사에 "강사·교육" 포함 30건 필터 → 타겟(파트너 강사)에 맞는 2명 선정
  2. 각 페르소나로 빙의해 **실제 배포 앱을 브라우저에서 신규 사용자 상태부터 직접 조작** (온보딩→프로필→훈련→검색→커스텀 시나리오 등록·리허설 완주→서버 백업→트레이너 대시보드, 모바일 화면 포함) — 리포트의 지적은 전부 실제로 재현된 관찰

  **① 신주희 (49세, 강원 홍천 전문대 교수, "걸어 다니는 매뉴얼" 완벽주의, 영어 중급)** — ★4.0 / NPS 8
  - 좋았던 점: "이건 영어 앱이 아니라 **강의 리허설 도구**다. 돌발상황 대응 시나리오만으로도 쓸 이유가 된다"
  - 아쉬운 점: "훈련을 중간에 멈추면 처음부터라니, 내 하루는 10분 단위로 쪼개져 있는데" / 마이크 실패 시 이유를 안 알려줌 / 레벨명이 전부 영어

  **② 김소윤 (28세, 서울 강동구 교육학 석사, 교육 콘텐츠 개발자 지망, 영어 상급, 스픽·말해보카 경험자)** — ★4.0 / NPS 7
  - 좋았던 점: "'내 대본 → 영어 변환 → 리허설' 루프는 스픽에도 없다. 학습 전이 관점에서 이보다 좋은 설계는 없다"
  - 아쉬운 점: "점수의 정체를 밝혀라 — 발음 평가가 아니라 음성 인식 일치율이다" / 커스텀 시나리오가 진도 통계의 사각지대 / 모바일 탭바 잘림 힌트 없음

- **피드백에서 알게 된 것 (→ Top 5 개선, 당일 배포 완료 ✅):**

  | # | 피드백 | 반영 |
  | --- | --- | --- |
  | 1 | 세션 중간 이탈 시 증발 (①②) | 카드마다 진행 저장 → "⏸️ 하다 만 훈련 → ▶️ 이어하기" |
  | 2 | 점수를 발음 평가로 오해 (②) | "85점" → **"전달률 85%"** + 상시 설명 문구 |
  | 3 | 커스텀 시나리오 진도 미반영 (②) | 진도 탭·트레이너 대시보드에 내 시나리오 합산 |
  | 4 | 마이크 실패 안내 부족 (①) | 권한 확인 방법 + "자가 채점도 효과 동일" 안내 |
  | 5 | 모바일 탭 잘림 힌트 없음 (②) | 탭바 우측 페이드 그라데이션 |

  - 💡 가상 페르소나 피드백의 품질은 페르소나의 "리얼함"보다 **실제 제품을 진짜로 조작해 보느냐**에서 갈렸다. 세션 증발·모바일 탭 잘림은 상상만으로는 절대 안 나오는 지적이었다.
  - 💡 상반된 배경(49세 중급 vs 28세 상급)인데 결론이 같았다 — "범용 영어앱과 싸우지 말고 리허설 도구로 가라." 페르소나 2명이 사실상 **포지셔닝 검증**이 됐다.
