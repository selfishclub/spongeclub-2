# Workshop English OS — 가상 페르소나 사용성 피드백 (4주차 미션)

## 방법론

1. **페르소나 소싱**: NVIDIA가 공개한 [Nemotron-Personas-Korea](https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea) 데이터셋(한국 인구통계 62개 변수 기반 합성 페르소나 600만 건, CC BY 4.0)에서 rows API로 600건을 수집하고, 직업·전문 서사에 "강사·강의·교육·훈련"이 포함된 30건을 필터링했다.
2. **선정 기준**: 이 OS의 실제 타겟(강사양성과정 파트너 강사)에 부합하면서 서로 다른 관점을 주는 2명을 선정 — ① 영어에 부담을 느끼는 중년 현직 강사, ② 상용 영어앱에 익숙한 20대 예비 강사.
3. **시뮬레이션**: 각 페르소나로 빙의하여 **실제 배포 코드가 도는 앱을 브라우저에서 직접 조작**했다. 신규 사용자 상태(저장 데이터 초기화)에서 시작해 온보딩 → 프로필 → 오늘의 훈련 → 표현 검색 → 시나리오 리허설(커스텀 등록 포함) → AI 코치 → 서버 백업 → 트레이너 대시보드까지 전 과정을 수행하고, 페르소나의 나이·직업·성격·영어 수준의 렌즈로 관찰을 기록했다. 데스크톱과 모바일(375px) 뷰포트를 모두 확인했다.
4. **산출물**: 페르소나별 리포트 2건 (사용 여정 로그 + 좋았던 점 + 불편한 점 + 개선 제안 + 평점).

| 1 | **훈련 세션 이어하기** — 중간 이탈 시 세션 증발 (A·B 공통) | 카드를 채점할 때마다 진행 상태를 저장. 재방문 시 "⏸️ 하다 만 훈련이 있어요 → ▶️ 이어하기 (N개 남음)" 카드 표시. 당일에 한해 이어하기, 완주 시 자동 정리 |
