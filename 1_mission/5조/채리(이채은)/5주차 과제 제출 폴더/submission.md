# 5주차 — 마지막 과제 🏁

> 이번 기수의 마지막 과제예요. 과정과 소회를 기록해주세요. (다 못 채워도 OK!)

여행 블로그의 **소재 수집 → 글감 선정 → 초안 → 검수 → 제휴 링크 발급 → 플랫폼 임시저장 → 성과 분석**까지 전 과정을 AI 에이전트(Claude Code)로 무인화하고, **발행 승인만 사람이 하는** Human-in-the-loop 시스템을 3일 만에 구축했습니다.

## 🎯 과제 1. 구현, 그 다음의 것

![과제 1 안내](https://github.com/selfishclub/spongeclub-2/raw/main/_meta/week5/mission1.png)

> 만드는 건 끝났는데 — 그 다음이 진짜 시작이에요

- **지금 걸려 있는 고민 하나:**
  **"다 만들었는데 — 이걸 내가 꾸준히 굴려서 진짜 수익까지 갈 수 있을까?"**
  시스템은 완성됐지만, 성공/실패는 **지금 판정할 수가 없습니다.** 이 시스템의 공식 성장 지표는 *"사람이 고친 문장 비율의 감소"*(= 시스템이 나를 닮아가는가)인데, 이건 발행 회고가 최소 5편은 쌓여야 나오는 숫자거든요. 즉 **'완성'이 끝이 아니라 시작점**입니다.

- **그게 왜 고민인지 (무엇이 걸리는지):**
  처음 풀려던 문제가 "사람의 시간이 병목"이었는데, 자동화로 병목을 없앤 게 아니라 **"발행 승인 + 문체 교정"이라는 작은 병목으로 옮겼을 뿐**이에요. 그 작은 한 칸조차 매주 지속되지 않으면 시스템은 조용히 죽습니다. 게다가 자동화는 플랫폼 약관상 **회색지대**라, 수익 기반인 계정 자체가 날아갈 리스크를 안고 갑니다.

- **어떻게 풀어볼 생각인지:**
  - **마찰 최소화로 지속 가능성 확보:** 주 3회 초안은 무인 생성, 사람은 승인만 (리허설에서 소요 13분·개입 0회로 실증). "매번 실행해야 하는 일"을 남기지 않는 게 지속의 핵심.
  - **가설을 지표로 판정:** 발행 회고마다 "고친 문장 비율"을 기록 → 5편 안에 실제로 줄어드는지 자동 판정.
  - **리스크는 보수 운영:** 임시저장까지만·사람 속도 입력·캡차 시 즉시 중단. 성공보다 **계정을 지키는 것**을 1순위로.

- **필요한 게 있다면 무엇인지:**
  꾸준함을 지탱할 **외부 장치**(마감·동료 피드백)와, 내 문체가 진짜 읽히는지 확인해줄 **실사용자 2~3명의 반응**, 그리고 수익 가정을 재조정할 **3개월치 실데이터**.

## 🏁 과제 2. 구현 마무리 + 실제 유저 피드백 받기

![과제 2 안내](https://github.com/selfishclub/spongeclub-2/raw/main/_meta/week5/mission2.png)

> 시작할 때 "이번엔 이건 꼭 만들겠다" 했던 것 — 지금 어디까지 왔나요?

- **최종 완성한 것 (지금 어디까지):**
  "여행 중 폰에 던지면 → 발행 직전 임시저장까지" 전 과정이 **무인으로 한 바퀴 완주**했습니다.
  - **구성:** 규칙 문서 5종(지능) + 파이썬 스크립트 10종(손발) + 스케줄 2개(심장·비정각+지터) + 메신저 봇(입출력) + JSON 기억(글감대장·링크장부·통계)
  - **설계 원칙 4:** ① 지능은 코드가 아니라 문서(대본)에 ② 사람은 마지막 안전선이자 유일한 선생님(수정 diff가 학습데이터) ③ 모든 실패는 신호가 되어야 한다(성공 `OK`/실패 `FAIL:<단계>` 출력 계약) ④ 깨지기 쉬운 것엔 폴백(스티커→문구, 카드링크→텍스트링크)
  - **구현 방식:** 구현 자체도 에이전트 오케스트레이션 — 10개 태스크 분업 + 독립 리뷰 루프가 **운영 전 Critical급 결함 6건**을 잡음(본문 오염 버그·링크 유실 경로·허위 서술 반증 등)

- **🚀 실제 배포 URL:**
  시스템 본체는 **개인 PC에서 도는 로컬 무인 실행**이라 공개 서비스 URL은 없습니다(의도적 — 자동 발행·비밀번호 저장 없음). **공개 산출물 = 네이버 블로그**입니다 → https://blog.naver.com/ice2160 (첫 발행 예시: https://blog.naver.com/ice2160/224356903200)

- **결과물 (링크·스크린샷 — 이미지는 `이미지첨부/` 폴더에):**
  - **엔드투엔드 리허설 완주:** 실소재(음성 인터뷰 1 + 사진 96장)로 글감 선정 → 키워드 실측(월 검색량 1.6만 확보) → 사진 9장 자동 선별·SEO 파일명 → 4관점 검수 전항목 합격 → 제휴 링크 2건 발급 → 대가성 스티커 자동 삽입 → 임시저장. **소요 13분, 사람 개입 0회.**
  - **실발행 2회 + 성과 분석 가동:** 자동 생성 초안 실제 발행, 발행 회고 루프(초안 vs 최종본 diff) 정상 작동. 누적 제휴 클릭 약 2천 건을 라벨 체계로 재구성해 깔때기(노출→조회→클릭→전환) 자동 진단 중.
  - 상세·스크린샷은 첨부 보고서 참조.

- **받은 유저 피드백:** (직접 작성 — 스폰지클럽 내 모집 예정)

## 📣 과제 3. SNS에 남기기

![과제 3 안내](https://github.com/selfishclub/spongeclub-2/raw/main/_meta/week5/mission3.png)

> 구현했던 것들 + 그 다음 단계에 대한 생각

- **구현했던 것들 (무엇을 / 어떻게 굴러가는지 / 뭐가 달라졌는지):**
  - **무엇을:** 여행 블로그 콘텐츠 파이프라인 완전 자동화 (발행 승인만 사람)
  - **어떻게 굴러가는지:** 폰으로 음성·사진 투척 → 4시간마다 수집(음성 자동 전사·얼굴 자동 모자이크) → 월·수·금 저녁 무인 회차가 절차 문서를 대본 삼아 초안·검수·임시저장 → "발행 버튼만 누르면 돼요" 알림 → 사람이 확인·수정·발행 → 일요일 주간 분석 자동 발송
  - **뭐가 달라졌는지:** 글쓰기 노동이 **"승인 노동"으로 압축**됨. 그리고 가장 큰 배움 — **"AI 글이 왜 마음에 안 드는지"를 숫자로 잡았다:** 내가 과거 쓴 글 6편(367문장)과 AI 초안을 정량 비교하니 행갈이 길이(내 글 18±21자/줄 vs AI 43자/줄)·느낌표 밀도(15±37개 vs 2개)·어미 분포("-더라구요" 15% vs 6%)가 확연히 달랐음. 이를 "내 목소리 가이드" 12규칙 + **검수 단계의 정량 문체 검사**로 못박음. → *AI 콘텐츠 품질의 관건은 모델이 아니라 개인 문체의 정량 명세였고, 그 명세는 사람이 고친 흔적에서 자동 학습된다.*

- **다음 단계 생각 (뭘 더 하고 싶은지 / 남은 것 / 어디로):**
  - **문체 수렴 장기 추적:** "수정 비율 감소"가 실제로 일어나는지 5편 이상 회고로 검증
  - **수익 가정 재조정:** 3개월 실데이터로 편당 수익·"공실률"(수익 0원 글 비율) 재산정
  - **남은 기술 과제:** 썸네일 카드형 링크 자동 삽입의 순서 비결정성 버그 해결(현재는 텍스트 링크로 폴백 운영)
  - **확장 검토:** 텔레그램→카톡 진입 장벽, 여행 외 카테고리(뷰티 리뷰 등), 팀 확산용 "시스템 해부 문서(아키텍처+설치 가이드)"

- **SNS 인증 링크:** (직접 작성 후 링크 첨부)
