# PRD — 여행 블로그 반자동 수익화 파이프라인

> 2026-07-24 작성 · 구현 환경: Claude Code + 텔레그램 (채팅으로 조작)
> 기술 구조와 상세 배경은 `blog\docs\PRD-블로그-파이프라인.md` 참고. 이 문서에는 결정만 담음.

## ① 문제 정의

- 누가: 본업이 있는 직장인 블로거
- 언제: 여행 다녀온 직후 2~3주 — 글쓰기에 제일 좋은 시기인데, 하필 밀린 일로 제일 바쁜 시기
- 무엇을 못 하나: 글을 못 씀. 기억은 며칠이면 흐려지고, 사진 수백 장만 갤러리에 남음. 가격·가는 길 같은 정보는 처음부터 다시 검색해야 함
- 지금까지 버틴 방법 (대체재)
    1. 주말에 2~3시간씩 들여 직접 쓰기 → 몇 주 못 가고 지침
    2. ChatGPT에 "발리 후기 써줘" → 겪지도 않은 얘기가 섞인 가짜 후기가 나와서 못 씀
    3. 포기 → 제일 흔한 경우
- 문제의 핵심: 세 방법 모두 "일주일에 2~3편은 올려야 수익이 시작된다"는 최소 조건을 못 채움

## ② 주요 페르소나 (한 명)

- 상황: 여행에서 돌아온 지 2주째. 갤러리에 사진 400장, 발행한 글 0편
- 배경: 블로그 부수입을 결심하고 제휴 마케팅 계정까지 만들어 둠. 그런데 퇴근 후 글 한 편을 완성할 힘이 없음
- 기술 수준: 명령어를 복사해서 붙여넣는 정도까지. 밖에서는 휴대폰이 전부
- 실제로 한 말
    - **"저거 매번 실행해야 해? 좀 더 편한 방법 없을까?"** → 귀찮은 일이 하나라도 남으면 결국 안 쓰게 됨
    - **"시간이 걸려도 좋으니, 점점 글 퀄리티가 높아지는 루프를 만들고 싶어."** → 원하는 건 글 한 편이 아니라, 쓸수록 좋아지는 시스템

## ③ 주요 가치 · 소구 방식

- 끝까지 지키는 것 한 줄: **경험은 지어내지 않는다. 내가 실제로 말한 것만 글이 된다**
- 페르소나의 언어로 번역: **"여행 중에 폰에 대고 말만 해두세요. 집에 오면 내 말투로 쓰인 초안이 기다려요. 다듬어서 발행 버튼만 누르면 됩니다."**

**시중 대안들이 이 페르소나에게 안 통하는 이유**

| 대안 | 뭘 해주나 | 왜 안 통하나 |
| --- | --- | --- |
| AI 글쓰기 서비스 (뤼튼, ChatGPT 등) | 주제를 주면 글을 통째로 생성 | 겪지 않은 경험을 지어냄 → 가짜 후기. 네이버 저품질 위험 + 본인이 스스로 못 견딤. 소재 수집·발행 후 학습 같은 "루프"가 없음 |
| 자동 포스팅 도구 (매크로·SaaS) | 대량 생산 + 자동 발행 | 자동 발행 자체가 저품질 제재 1순위 → 수익 기반인 계정을 걸고 하는 도박 |
| 대필 외주 | 돈 주면 사람이 써줌 | 편당 비용이 계속 나가고, 내 경험·내 말투가 아님. 주 2~3편을 지속할 수 없는 구조 |
| 키워드 분석 도구 (키워드마스터 등) | 검색량·경쟁도 분석 | 분석까지만 하고 글은 안 써줌. 우리는 같은 분석이 초안 생성에 바로 연결됨 |
| 강의 + 노션 템플릿 루틴 | 방법론과 양식 제공 | 결국 전부 사람이 해야 함 → "퇴근 후 힘이 없다"는 원래 문제가 그대로 남음 |

비어 있는 자리: **"진짜 경험만 쓰는 반자동"** — 위 대안들은 전부 "다 사람이 하거나(지속 불가), 다 기계가 하거나(가짜+제재 위험)" 양극단에 있음. 이 프로덕트는 그 사이의 자리를 차지함

## ④ 핵심 기능 (위 약속을 지탱하는 것만)

1. 잃어버리지 않는 소재함
    - 여행 중 텔레그램 채널에 음성·사진·메모를 던져두면, 집 컴퓨터가 4시간마다 알아서 가져감
    - 음성은 글로 바뀌고, 사진 속 얼굴은 자동 모자이크
    - 컴퓨터가 며칠 꺼져 있어도 소재는 안 사라짐
2. 내가 한 말로만 쓰는 초안
    - 여행 하나를 글감 여러 개로 나누고, 이 글을 검색할 사람을 정한 뒤, 실제 검색량 데이터로 제목 결정
    - 초안은 내 문체로 작성. 모르는 건 지어내지 않고 나에게 2~3개만 질문
3. 검사를 통과해야 나오는 초안
    - 4가지 검사: 읽는 사람 입장 / 네이버 노출 / 사람이 쓴 글 같은지 / 수익 구조가 안전한지
    - 통과하면 네이버 에디터에 그대로 붙여넣는 파일까지 생성. 발행에 약 10분
4. 쓸수록 나를 닮아가는 학습
    - 발행 후 "발행했어 + 링크" 한 줄이면, 발행본과 초안을 비교해 내가 고친 부분을 학습
    - 같은 수정이 반복되면 규칙으로 저장

**넣고 싶었지만 뺀 것 (+ 이유)**

- 자동 발행 → 네이버에 걸리면 블로그가 검색에서 통째로 사라짐(저품질 제재). 수익의 뿌리라 도박 불가
- n8n 같은 자동화 서버 → 배우는 데 드는 품이 사용자 수준과 안 맞음
- 알림·명령까지 채널 하나로 실시간 통합 → 채널 글엔 즉시 답을 못 하는 구조. 알림 배달까지만 통합하는 절충안으로 진행 중
- 새 제휴 링크 자동 발급 → 로그인 비밀번호를 AI가 다루지 않는다는 원칙. 이미 만든 링크 재사용까지만 자동화

## ⑤ 성공 기준 ("좋아요"가 아니라 행동으로 확인)

- 발행이 반복되는가: 주 2~3편 발행 4주 연속 유지 (1호 글 발행 완료, 발행 작업 약 10분 실측)
- 고치는 양이 줄어드는가: 발행 때마다 기록하는 "내가 고친 부분"이 편마다 감소. 목표는 5편 안에 거의 고칠 곳 없는 초안
- 수익이 보이는가: 6개월 안에 제휴 수익 월 30만 원
- 절대 깨지면 안 되는 조건: 네이버 저품질 제재 0회 — 이게 깨지면 위 성공은 전부 무효

**목표 수치의 근거 (첫 가설 — 3개월 차에 실데이터로 다시 조정)**

- 월 30만 원의 근거
    - 하한선: 세시간전 최소 출금액이 5만 원 → 30만 원은 "매달 출금하는 게 당연해지는" 수준. 용돈이 아니라 부수입이라고 부를 수 있는 최소 크기
    - 역산: 6개월간 주 2~3편이면 글 50~70편이 쌓임 → 편당 월 5천 원 안팎의 수익이면 도달 가능한 숫자. 글 하나가 대박 나야 하는 목표가 아니라, 쌓인 글이 조금씩 버는 구조를 전제로 함
    - 솔직한 한계: 편당 5천 원이 실제로 나올지는 아직 모름. 그래서 "첫 가설"이며, 첫 통계가 쌓이는 3개월 시점에 숫자를 다시 잡기로 함
- "5편 안에 무수정 초안"의 근거
    - 1호 글 발행 후 비교에서 확인된 사실: 사람이 고친 곳 대부분이 반복되는 패턴이었음 (글 시작하는 방식, 정보 배치 순서, 말투)
    - 패턴은 한 번 배우면 다음 글부터 사라짐 → 반복 패턴이 3~5회 안에 바닥날 것이라는 가설
    - 측정 방법: 발행 때마다 "고친 부분"을 기록 중이라, 이 가설은 5편이면 자동으로 판정됨

## ⑥ 만들지 않을 것 (안 적으면 기능이 계속 늘어남)

- 자동 발행: 영원히 없음. 발행 버튼은 항상 사람이 누름
- 경험 창작: AI가 느낌·경험을 만들어내는 기능은 어떤 형태로도 없음
- 대량 생산: 하루 열 편씩 찍기, 계정 여러 개 돌리기 없음
- 다른 플랫폼 확장: 티스토리·워드프레스는 네이버에서 성공 기준 달성 후 검토
- 화면 있는 도구: 키워드 조회는 명령 한 줄로 충분. 대시보드·앱 안 만듦
- 제품화: 팀원에게는 설치 문서까지만. 인스톨러·서비스화는 범위 밖
