# 4주차 — 기획·구현 → 검증 → 기록 🧪

> 과제를 진행하며 과정과 결과를 기록해주세요. (다 못 채워도 OK, 한 것 위주로!)

## 🎯 과제 1. PRD 기획 및 구현
> 주요 가치 · 페르소나 · 소구 방식을 담은 PRD → 구현까지

만든 것: **여행 중 폰에 던진 음성·사진·메모가, 집에 오면 발행 직전 초안이 되어 기다리는 반자동 블로그 파이프라인.** PRD를 먼저 고정하고(무엇을·왜·어디까지) 그대로 구현했습니다.
📎 **PRD 원문 전문 → [PRD-여행블로그-파이프라인.md](PRD-여행블로그-파이프라인.md)** (아래는 핵심 발췌)

- **주요 가치:**
  끝까지 지키는 한 줄 — **"경험은 지어내지 않는다. 내가 실제로 말한 것만 글이 된다."**
  시중 AI 글쓰기 도구는 겪지 않은 경험을 지어내(가짜 후기 → 네이버 저품질 위험), 자동 포스팅 도구는 자동 발행 자체가 제재 1순위입니다. "다 사람이 하거나(지속 불가) / 다 기계가 하거나(가짜·제재)"의 양극단 사이, **"진짜 경험만 쓰는 반자동"** 이라는 빈자리를 차지하는 것이 이 프로덕트의 가치입니다.

- **페르소나:**
  여행에서 돌아온 지 2주째, **갤러리엔 사진 400장, 발행한 글 0편**인 직장인 블로거. 부수입을 결심하고 제휴 계정까지 만들어 뒀지만 퇴근 후 글 한 편 쓸 힘이 없습니다. 기술 수준은 "명령어 복붙"까지, 밖에선 휴대폰이 전부.
  실제로 뱉은 말 2개 —
  - *"저거 매번 실행해야 해? 좀 더 편한 방법 없을까?"* → 귀찮은 일이 하나라도 남으면 결국 안 쓰게 됨
  - *"시간이 걸려도 좋으니, 점점 글 퀄리티가 높아지는 루프를 만들고 싶어."* → 원하는 건 글 한 편이 아니라 쓸수록 좋아지는 시스템

- **소구 방식:**
  페르소나의 언어로 번역한 한 문장 — **"여행 중에 폰에 대고 말만 해두세요. 집에 오면 내 말투로 쓰인 초안이 기다려요. 다듬어서 발행 버튼만 누르면 됩니다."**

- **구현한 것 (링크·스크린샷 — 이미지는 `이미지첨부/` 폴더에):**
  파이프라인이 이번 주 **실제로 한 바퀴 돌았습니다.**

  | 구간 | 내용 | 상태 |
  |---|---|---|
  | 수집 | 텔레그램 채널 → 로컬 Whisper 음성 변환 · 얼굴 자동 모자이크(사진 31장·얼굴 59개 실증) → 여행별 소재 노트 | ✅ 4시간마다 자동 |
  | 브리핑 | 매일 19시 새 소재 요약·글감 제안을 텔레그램 발송 | ✅ 자동 |
  | 글 생성 | 글감 분해(수익성) → 글별 독자 페르소나 → 실제 검색량 데이터로 제목 결정 → 인터뷰(≤3문항) → 사실 검증 → 초안 | ✅ 실증 |
  | 품질 게이트 | 4관점 검수: 독자·설득 / 네이버 SEO / AI냄새 / 수익 구조(공정위 고지) — 통과해야 발행 파일 생성 | ✅ 18/18 통과 |
  | 발행 준비 | 스마트에디터 붙여넣기용 HTML 자동 생성(표·행갈이 유지) — 발행 작업 약 10분 | ✅ |
  | 성장 루프 | 발행본 ↔ 초안 diff 회고 → 반복 수정은 규칙으로 흡수 | ✅ 1호 글 회고 가동 |

  **첫 실전 결과물 — 발리 아야나 락바 후기** (실소재: 음성 3건 · 사진 31장에서 출발)
  - 발행된 글(네이버): https://blog.naver.com/ice2160/224356903200
  - 🎬 **"음성 3개가 발행된 글이 되기까지" 케이스 스토리 → [케이스스토리-락바.html](케이스스토리-락바.html)**
    *(파일을 내려받아 브라우저로 열면, 흩어진 음성 3개가 한 편의 글이 되는 전 과정을 간접 체험할 수 있게 정리했습니다.)*

## 🗣 과제 2. 유저 피드백 받기
> 실제 2명 이상 + 플러스 알파로 가상 페르소나

- **실제 유저 피드백 (2명 이상):** (직접 작성)

- **가상 페르소나 피드백:**
  통계청 인구 분포 기반 합성 페르소나(NVIDIA Nemotron-Personas-Korea)로 **타겟 인접 2명 + 타겟과 먼 3명**을 뽑아 PRD를 리뷰받았습니다. *(가설 검증 도구이지 실제 사용자 조사가 아니라는 점은 명시. 여기서 나온 반응은 "실제로 물어볼 질문 목록"으로 사용)*
  📎 **가상 패널 리뷰 전문 → [가상패널-리뷰.md](가상패널-리뷰.md)**
  - **박하진**(27·광고 디자이너, 타겟 인접): "'내 말투로 쓰인 초안'이 핵심 카피 맞아요." → 날카로운 질문 *"사진 31장 중 어떤 8장을 쓸지는 누가 골라요?"* (다음 병목 = 사진 선별)
  - **김혜인**(28·재택 에디터 준비, 잠재 1순위): "과정이 3단계 넘어가면 안 하게 돼요." → *"저는 텔레그램을 안 써요. 카톡은 안 되나요?"*, *"여행 말고 뷰티 리뷰에도 되나요?"* (진입 장벽 · 카테고리 확장)
  - **고성호**(61·부동산 영업, 수익성 검증): "이건 노동이 아니라 자산을 쌓는 구조네. 글 70편이 임대 물건 70개인 셈." → *"공실률(수익 0원 글 비율)은 왜 없어요?"*
  - **김재성**(26·블로그를 읽기만 하는 독자): *"내돈내산 절반이 가짜인 거 다 알아요. 그래서 사진만 봐요 — 메뉴판·영수증·대기줄 사진 있는 글만 걸러 읽어요."* (실사 증거 강제가 독자 신뢰와 정확히 일치)
  - **신상규**(72·비타겟): "기계가 썼다고 하면 나 같은 사람은 그 식당 안 가." (범위를 좁게 잡은 것이 옳았다는 반증 + 원칙의 유효성 확인)

- **피드백에서 알게 된 것:**
  - 다음 병목은 글이 아니라 **사진 선별·배치**다 (박하진).
  - 확산 시 **텔레그램 진입 장벽**과 **카테고리 확장** 질문이 반드시 나온다 → PRD "뺀 것"에 근거를 명시할 것 (김혜인).
  - 수익 가정에 **"공실률"(수익 0원 글 비율)** 이 빠져 있었다 → 3개월 실데이터로 보강 (고성호).
  - **실사 증거(메뉴판·영수증) 우선 배치**는 독자 신뢰의 핵심 — 글쓰기 규칙 방향이 맞았음을 독자 관점에서 확인 (김재성).

## 📣 과제 3. SNS 기록 남기기
> 기획 · 구현 · 피드백의 전 과정과 소회를 기록으로

- **기록 내용 (소회):**
  이번 주는 "글을 대신 써주는 도구"가 아니라 **"경험을 지어내지 않겠다는 원칙을 코드로 강제하는 시스템"** 을 만든 한 주였습니다.
  - **PRD를 먼저 고정하니 구현이 흔들리지 않았다.** "무엇을·왜·어디까지"를 한 문서에 박아두니, 넣고 싶은 기능(자동 발행 등)을 스스로 쳐낼 수 있었습니다. 특히 *자동 발행은 영원히 없음* — 계정을 거는 도박이라 원칙으로 거부했습니다.
  - **가상 패널은 정답이 아니라 "물어볼 질문"을 줬다.** 공실률·카톡·카테고리 확장처럼, 혼자선 못 봤을 구멍을 짚어줬습니다.
  - **정직한 기록:** 1호 글(락바 후기)은 초안에서 **손질이 꽤 많이 들어갔습니다.** 도입부를 통째로 바꾸고 말투도 여러 문장 고쳤어요. 그래서 "수정량 감소"의 출발점(베이스라인)을 "많음"으로 정직하게 잡았습니다 — 과장은 신뢰를 깎으니까. 대신 반복된 수정 패턴(도입 공식·섹션 순서·사진 기반 추정 금지)은 규칙으로 흡수해, **다음 글부터 줄어드는지**를 5편 안에 판정할 계획입니다.
  - 결국 이 시스템의 약속은 하나 — **쌓일수록 나를 닮아가고, 끝까지 진짜 경험만 쓴다.**
