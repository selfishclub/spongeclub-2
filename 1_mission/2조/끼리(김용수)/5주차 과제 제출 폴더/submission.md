## 🎯 과제 1. 구현, 그 다음의 것

![과제 1 안내](https://github.com/selfishclub/spongeclub-2/raw/main/_meta/week5/mission1.png)

> 만드는 건 끝났는데 — 그 다음이 진짜 시작이에요.

제가 만든 서비스는 두 개예요. 각각 지금 걸려 있는 고민을 꺼내봅니다.

### 고민 ① 크리에이터 시작 가이드 — "무료로 열고, PD로서 어떻게 활용하지?"

- **지금 걸려 있는 고민 하나:** 이 서비스(creators)는 **무료로 배포**해서 예비 크리에이터 누구나 쓰게 하고 싶은데, 그렇게만 두면 서비스 자체로는 남는 게 없어요. 저는 네이버 블로그 **『끼리씨의 용인수집』**과 유튜브 **『단수민의 혼신기록』**을 운영하는 PD인데, **이 진단 서비스를 제 채널들과 어떻게 엮어야 시너지가 날지**가 안 잡힙니다.
- **그게 왜 고민인지 (무엇이 걸리는지):** '좋은 무료 도구'와 '내 채널 성장'이 따로 놀면, 만들어만 두고 방치될 것 같아요. 무료로 풀되 **① 사람들에게 진짜 도움이 되고 ② 동시에 내 블로그/유튜브로도 연결되는** 접점을 못 찾았습니다.
- **어떻게 풀어볼 생각인지:** 몇 가지 방향을 놓고 저울질 중이에요.
  1. **리드마그넷(유입 자석)으로** — 진단 결과 화면 끝에 "더 궁금하면" → 블로그/유튜브로 자연 유입. 반대로 블로그·유튜브 콘텐츠에서 "당신에게 맞는 플랫폼 3분 진단"으로 유입.
  2. **유튜브 콘텐츠 소재로** — 『단수민의 혼신기록』에서 *구독자 사연 진단 리액션*, *"나는 어떤 크리에이터?" 진단 결과로 채널 기획* 같은 시리즈.
  3. **결과 공유 → 바이럴** — 진단 결과를 이미지/링크로 공유하는 기능을 붙여 자연 확산.
  4. **무료 유지 + 심화만 유료화** — 진단은 무료, '1:1 채널 설계 코칭'이나 '플랫폼별 첫 30개 콘텐츠 템플릿'만 유료.
- **필요한 게 있다면 무엇인지:** ① 진단 결과 **공유 기능**(이미지 저장/링크) ② 어느 채널에서 유입됐는지 **트래킹**(UTM) ③ 실제 예비 크리에이터 **표본 몇 명의 진단 후기**.

### 고민 ② 끼리 블로그 OS — "컨셉을 갈아엎는데, OS·자동화를 어떻게 다시 짜지?"

- **지금 걸려 있는 고민 하나:** 블로그 컨셉을 **『끼리씨의 용인수집』 → 『아빠컨셉(요리·식자재·가전)』**으로 전환하려고 해요. 그런데 컨셉을 바꾸면 지금의 OS(대시보드)·콘텐츠 파이프라인·수익화 흐름을 **거기에 맞춰 다시 짜야** 하고, 특히 **아이디어 수집 → 글 작성·관리 → 발행 → 수익화**를 잇는 자동화가 아직 수동이라 손이 많이 갑니다.
- **그게 왜 고민인지 (무엇이 걸리는지):** ① 컨셉을 바꾸면 용인 중심으로 쌓아둔 카테고리·프롬프트·자산을 새 컨셉(요리·식자재·가전)으로 재편해야 함 ② 글감·아이디어가 여기저기 흩어지고, 작성 글이 **옵시디언에 정리되지만 대시보드와 연결이 안 됨** ③ 컨셉 전환의 첫 성과(브랜드커넥트 수익화)로 이어질 실제 글이 아직 안 나옴.
- **어떻게 풀어볼 생각인지:**
  1. **디스코드 채널 생성(끼리 블로그 페르소나)** — 아이디어·글감을 던져두는 수집 통로로.
  2. **옵시디언 연동** — 작성한 글을 저장·관리되게 연결.
  3. **기존 OS 대시보드에 메뉴 추가** — 옵시디언에 누적된 콘텐츠 현황 + 아이디어 추가 뷰.
  4. **컨셉 전환 첫 실행 = 브랜드커넥트 연결 글 3개 발행** — ① 요리도구 ② 간편식품 ③ 여행후기.
- **필요한 게 있다면 무엇인지:** ① 디스코드 봇/채널 세팅 방법 ② **옵시디언 ↔ 대시보드 연동** 방식(누적 글·아이디어 현황을 대시보드로 끌어오기) ③ 새 컨셉에 맞는 브랜드커넥트 매칭 상품 리서치.

## 🏁 과제 2. 구현 마무리 + 실제 유저 피드백 받기

![과제 2 안내](https://github.com/selfishclub/spongeclub-2/raw/main/_meta/week5/mission2.png)

- **최종 완성한 것 (지금 어디까지):** 5주 동안 배포까지 끝낸 서비스 **2종**을 최종 완성했어요.

  **① 끼리 블로그 OS** — 블로그 운영을 돕는 매일 여는 대시보드
  - 2주차 Notion DB 뼈대 → 3주차 **Vercel 배포 웹앱**으로 이전(Next.js + Tailwind).
  - 홈·콘텐츠 파이프라인·프롬프트 스튜디오·수익·성과·트래픽·링크 허브 **6개 탭 + 실시간 시세 위젯 + BGM**을 한 화면에 통합.

  **② 크리에이터 시작 가이드** — 예비 크리에이터를 위한 3분 자가진단
  - 6문항 진단 → 맞춤 **주제·포맷·플랫폼 TOP3·업로드 주기·성장 로드맵·첫 콘텐츠 아이디어** 제시.
  - 로그인 없이 브라우저 저장, 무료.

- **🚀 실제 배포 URL:**
  - 끼리 블로그 OS: https://draphant-blog.vercel.app/ (소스: https://github.com/Draphant/draphant_blog)
  - 크리에이터 시작 가이드: https://creators-virid.vercel.app/ (소스: https://github.com/Draphant/creators)

- **결과물 (링크·스크린샷 — 이미지는 `이미지첨부/` 폴더에):** 위 라이브 URL에서 바로 확인 가능. (스크린샷은 `이미지첨부/` 폴더에 첨부 예정)

- **받은 유저 피드백:**
  - **가상 페르소나 피드백(4주차):** `virtual-customer-feedback` 스킬로 예비 크리에이터 페르소나 4명 인터뷰. 공통 지적 = ① *"왜 이 플랫폼인지 근거가 없다"* ② *"진짜 벽은 결정이 아니라 그 다음 실행"* ③ *"이미 방향 있는 사람에겐 정체성 찾기가 안 와닿는다"*.
  - **→ 반영(5주차 수정):** 결과 페이지에 **『왜 이 플랫폼이 1순위일까?』 근거 블록**(내 답변 태그 + 서술형 근거)과 **『첫 발행까지 3스텝』 실행 체크리스트**(계정 개설 → 첫 주제 선택 → 이번 주 발행)를 추가 배포.
  - **실제 유저 2명 피드백:** 아직 모집 못함 — 다음 단계로 남김(스폰지클럽 내 모집 예정).

### 🔧 5주 개선·피드백 반영 이력 (요약)

| 서비스 | 받은 피드백 / 스스로 발견 | 수정한 것 |
|---|---|---|
| 블로그 OS | "OS가 여러 Notion·CSV로 흩어져 안 열게 된다" | 매일 여는 **단일 대시보드**로 통합 |
| 블로그 OS | "수익 채널이 하나뿐" | 세시간전 어필리에이트를 **2번째 채널로 추가** |
| 블로그 OS | 배포 삽질(빌드 성공 ≠ 배포 성공) | CVE 취약버전 차단 → 패치판 교체 / 시세 CORS → **서버리스 프록시** |
| 크리에이터 가이드 | 페르소나: "추천 근거가 없다" | **『왜 이 플랫폼』 근거 블록** 추가 |
| 크리에이터 가이드 | 페르소나: "결정 다음 실행이 벽" | **『첫 발행 3스텝』 실행 체크리스트** 추가 |
| 크리에이터 가이드 | 페르소나: "로그인 요구하면 이탈" | 가입 없이 바로 진단(유지) |

- **다음 단계 생각 (뭘 더 하고 싶은지 / 남은 것 / 어디로):**
  - 크리에이터 가이드를 **무료로 열고**, 『끼리씨의 용인수집』·『단수민의 혼신기록』 채널과 **유입/콘텐츠 소재로 연결**(과제1 고민 ①).
  - 블로그 OS는 컨셉을 **아빠컨셉(요리·식자재·가전)**으로 전환하고, 디스코드 수집 → 옵시디언 관리 → 대시보드 연동 자동화 + 브랜드커넥트 글 3개 발행(과제1 고민 ②).
