# 4주차 — 기획·구현 → 검증 → 기록 🧪

> 과제를 진행하며 과정과 결과를 기록해주세요. (다 못 채워도 OK, 한 것 위주로!)

## 🎯 과제 1. PRD 기획 및 구현
> 주요 가치 · 페르소나 · 소구 방식을 담은 PRD → 구현까지

### 📌 한 줄 소개
반려견 트레이너가 **예약을 잡으면 그 일정이 바로 세션 기록 폼으로 이어지는** MIT DOG의 캘린더 기능. 예약과 기록을 따로 관리하지 않고 한 흐름으로 연결했다.

- **주요 가치:**
  - **끊기지 않는 흐름** — 예약 등록 → (교육 진행) → 예약 클릭 한 번으로 세션 작성 폼 진입 → 저장 시 회차 자동 부여. 트레이너가 "예약 어디 적었더라, 기록은 또 어디에" 하며 이중 입력하지 않아도 됨.
  - **보호자 리포트로의 연결** — 세션 기록이 그대로 보호자 전달사항까지 이어져, 3주차에 만든 "로그인 없이 열리는 보호자 리포트"와 자연스럽게 연결됨.

- **페르소나:**
  - 1인/소규모로 반려견 트레이닝 센터를 운영하는 트레이너. (본인이 반려견트레이닝센터를 운영 중이라 실무에서 겪는 불편을 직접 반영)
  - 상담·교육계획·세션 기록·보호자 소통을 혼자 다 처리해야 해서, 예약과 기록이 따로 놀면 관리가 새는 사람.

- **소구 방식:**
  - **핵심 메시지: "예약 하나가 곧 오늘 할 일이자 기록할 자리다."** 캘린더에서 예정된 일정을 누르면 바로 그 세션의 기록 폼(날짜·시간·장소·분야가 이미 채워진 채)이 열린다.
  - 완료 처리하면 회차 번호가 자동으로 매겨져, "이 반려견 몇 회차더라"를 트레이너가 따로 셀 필요가 없다.

- **구현한 것 (링크·스크린샷 — 이미지는 `이미지첨부/` 폴더에):**
  - **🔗 라이브 앱:** https://dog-training-app-eight.vercel.app/calendar (트레이너 로그인)
  - **구현 내용:** 캘린더에서 예약 일정 확인 → 일정 클릭 시 세션 작성 폼 진입("예정된 일정입니다. 내용을 채워 저장하면 완료 처리되고 회차 번호가 매겨집니다") → 진행 내용·반려견 반응(1~5점 척도+서술)·성공률/수행 데이터·특이사항·분석(이전 세션 대비)·다음 세션 계획·보호자 전달사항 기록 → 저장
  - **🖼 스크린샷:** _(세션 작성 폼 화면을 `이미지첨부/` 폴더에 저장 후 여기 연결 — 대화에서 캡처한 이미지 재사용 가능)_

## 🗣 과제 2. 유저 피드백 받기
> 실제 2명 이상 + 플러스 알파로 가상 페르소나
- **실제 유저 피드백 (2명 이상):** _(이번 주엔 진행하지 못함 — 다음 단계로 남김)_
- **가상 페르소나 피드백:** `virtual-customer-feedback` 스킬(NVIDIA Nemotron-Personas-Korea 기반)로 **패널 인터뷰** 진행. 타깃(반려견 트레이너, 세그먼트 C) 3명 + 인접 세그먼트 1명과 세션 작성 폼을 놓고 인터뷰.
  - **김세원(34, 스마트스토어 운영):** "세션 끝나고 바로 이 긴 폼을 채울 여력이 없어요. 결국 몰아서 쓰게 될 듯."
  - **최연옥(50, 치과 원장):** "항목은 당연히 있어야 하는데, 성공률이 텍스트박스라 통계로 못 뽑으면 축적한 기록이 의미가 없어요."
  - **고성호(61, 부동산 영업원):** "적을 게 너무 많아서, 이런 건 불러주면 대신 써주는 게 낫지."
  - **조승용(53, 자동차 전장 연구원·인접군):** "구성은 논리적인데, '이전 세션 대비 분석'을 적으려면 매번 지난 기록을 따로 찾아봐야 하니 결국 대충 쓰게 될 것 같아요."
- **피드백에서 알게 된 것:**
  1. **입력 부담이 공통 문제** — 세션 직후 현장에서 서술형 필드 다수를 즉시 채우기 부담스럽다는 반응이 4명 중 3명에서 나옴.
  2. **"기록은 있는데 데이터로 못 쓴다"** — 성공률이 자유 텍스트라 나중에 집계·그래프로 못 뽑는다는 지적(최연옥·조승용). 전문직·정밀직군일수록 이 부분에 더 민감.
  3. **이전 세션과의 비교가 수동** — "분석(이전 세션 대비)" 필드 옆에 직전 기록을 자동으로 보여주지 않아 실효성이 약함.
  - → **다음 개선:** ① 서술형 필드 축소 + 체크박스/척도 조합, 음성입력 검토 ② 성공률을 숫자(%) 표준 입력으로 변경 ③ "분석" 필드 옆에 직전 세션 요약 자동 노출. *가상 피드백은 방향 감각용이며, 실제 트레이너가 세션 직후/나중에 몰아서 중 어느 쪽으로 이 폼을 쓰는지는 진짜 피드백으로 확인 필요.*
