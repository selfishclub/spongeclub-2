## 🎯 과제 1. 구현, 그 다음의 것

![과제 1 안내](https://github.com/selfishclub/spongeclub-2/raw/main/_meta/week5/mission1.png)

> 만드는 건 끝났는데 — 그 다음이 진짜 시작이에요 (답이 안 나와 있어도 OK, 고민을 꺼내놓는 것 자체가 과제)
- **지금 걸려 있는 고민 하나:** 세션 기록에 사진·영상을 첨부할 수 있게 하고 싶은데, 저장 공간과 용량을 어떻게 감당할지가 걸림
- **그게 왜 고민인지 (무엇이 걸리는지):** 세션마다 사진 여러 장·영상까지 쌓이면 저장 용량이 빠르게 늘어나는데, 지금 배포 환경(Vercel)은 파일 저장용이 아니라 별도 스토리지가 필요함. 트레이너 수가 늘면 비용이 어떻게 커질지 감이 안 잡힘
- **어떻게 풀어볼 생각인지:** 원본을 그대로 올리기보다 업로드 시 압축하거나, 영상은 직접 저장 대신 외부 링크(유튜브 비공개 등)로 받는 식으로 가볍게 시작
- **필요한 게 있다면 무엇인지:** 무료/저비용으로 쓸 수 있는 이미지·영상 스토리지(Cloudinary, Supabase Storage 등) 중 뭐가 맞을지 판단, 혹은 이미 이런 문제를 겪어본 사람의 조언

## 🏁 과제 2. 구현 마무리 + 실제 유저 피드백 받기

![과제 2 안내](https://github.com/selfishclub/spongeclub-2/raw/main/_meta/week5/mission2.png)

> 시작할 때 "이번엔 이건 꼭 만들겠다" 했던 것 — 지금 어디까지 왔나요? (스폰지클럽 내 유저피드백 모집 가능)
- **최종 완성한 것 (지금 어디까지):** 트레이너 로그인 · 반려견 관리(진행중/교육종료 구분) · 상담·교육계획 기록 · 캘린더 기반 예약 → 세션 작성(진행내용·반려견반응·성공률·분석·다음계획·보호자 전달사항) · 보호자 리포트 공유 링크(로그인 없이 열람)까지 실제 배포 완료
- **🚀 실제 배포 URL:** https://dog-training-app-eight.vercel.app/
- **결과물 (링크·스크린샷 — 이미지는 `이미지첨부/` 폴더에):** _(로그인 화면·대시보드·캘린더·세션 작성 폼·보호자 리포트 스크린샷을 `이미지첨부/` 폴더에 저장 후 여기 연결)_
- **받은 유저 피드백:**
  1. "트레이너마다 기록하는 방식이나 중요하게 생각하는 항목이 다를 수 있으니, 기록 항목은 최대한 다양하게 준비해 두고 사용자가 필요한 항목만 골라 기본값으로 설정할 수 있는 커스터마이징 기능이 있으면 좋겠다."
  2. "보호자용 리포팅은 트레이너가 적어놓은 내용을 기반으로 좀 더 쉽게 풀어서 전달되면 좋겠다."

## 📣 과제 3. SNS에 남기기

![과제 3 안내](https://github.com/selfishclub/spongeclub-2/raw/main/_meta/week5/mission3.png)

> 구현했던 것들 + 그 다음 단계에 대한 생각 (아끼면 아무 일도 안 일어나요 — 꺼내놓는 순간 가장 많이 남아요)
- **구현했던 것들 (무엇을 / 어떻게 굴러가는지 / 뭐가 달라졌는지):**
  '나만의 OS'를 만들겠다고 시작했지만, 혼자 센터를 운영하다 보니 회사 다닐 때처럼 동료와 일정을 나누거나 워라밸을 구분할 여지가 없어졌고, 그래서 결국 센터 운영에 실제로 필요한 것들을 만들게 됐다.
  1. **영상 자동 편집(1주차)** — 운동별 구간을 색 마커로 찍어 영상을 자동으로 잘라주는 도구를 시도. 하지만 교육 중에 마커 찍는 작업까지 더하니 산만해져서, 지금은 다시 예전 방식(수동 편집)으로 돌아감.
  2. **체형 분석 도구(2주차)** — 반려견의 운동 전후 체형을 분석하는 기능. 아직 실무에 적용하진 않았지만, 꾸준히 디벨롭하면 유료 서비스로도 갈 수 있지 않을까 하는 생각이 듦.
  3. **교육 기록·보호자 리포팅 앱(3~4주차, MIT DOG)** — 실제 배포까지 완료. 예약을 넣고, 진행된 교육 내용을 정리하고, 보호자에게 리포팅하는 흐름. 아직 실사용 전이지만, 트레이너는 기록이 정리돼서 좋고 보호자도 정돈된 포맷으로 리포트를 받으니 서비스를 받는 느낌일 것 같다는 기대가 있음.
- **다음 단계 생각 (뭘 더 하고 싶은지 / 남은 것 / 어디로):**
  배포한 앱(MIT DOG)은 '행동에 대한 기록' 위주라서, 별도로 '운동 기록'을 위한 도구는 배포 없이 개인적으로 쓰는 용도로 만드는 중. 인스타그램 피드도 클로드와 함께 더 활발히 운영하고 싶음.
