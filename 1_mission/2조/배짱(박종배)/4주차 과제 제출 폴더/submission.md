# 4주차 — 기획·구현 → 검증 → 기록 🧪

> 3주차에 "실기기 배포"까지 끝낸 **온마음 말씀사진관**을, 4주차엔 **실제 사용자 + 가상 페르소나 5인 패널**로 검증하고 → 나온 피드백을 **그날 바로 앱에 반영**했습니다. "만들었다"가 아니라 **"검증하고 고쳤다"**가 이번 주 핵심입니다.

## 🎯 과제 1. PRD 기획 및 구현

### 주요 가치
**"어르신 한 분 한 분에게, 세상에 하나뿐인 '말씀 담긴 사진'을 그 자리에서 선물한다."**
- 선교·심방의 짧은 접점을 → **설치 없는 웹**(URL·QR만)으로 진입 장벽 0
- 결과물은 **즉석 인쇄본(감열지)** + **폰에 남는 컬러 원본**의 이중 구조 — "손에 쥐여드리는 따뜻함" + "오래 남는 기록"

### 페르소나
선교 현장은 "쓰는 사람"과 "받는 사람"이 다릅니다. 그래서 페르소나를 **의사결정·운영·사용 축**으로 나눴습니다. (가상 페르소나 5인 카드로 정리 — CC BY 4.0 합성 데이터 기반)

| 축 | 페르소나 | 핵심 관심 |
|---|---|---|
| 결정권자 | ICT 전공 목사 (54) | "설치 없이 된다"는 매력 / 그러나 운영 지속성 |
| 신중·리스크 | 노(老)신학·법 밝은 목사 (75) | 초상권·사진 저장 정책, 지속운영 부담 |
| 매주 운영 | 사역자·전도사 (40) | 주일 인력, 어르신의 촬영 부담 |
| 기술 담당 | 20대 전도사 (28) | 인수인계 매뉴얼·감열지 조달, 데이터 관리 |
| 사용 보조 | 어르신께 사용법 알려주는 분 (64) | 타이머·셀카 UI 난이도 |
| **최종 수혜자** | **독거·거동 어르신** | **부담 없이, 그 자리에서 받는 내 사진** |

### 소구 방식
- **설치 없는 웹** — 태블릿·폰 브라우저에서 URL/QR로 바로. 앱스토어·계정 없음
- **심방 동행형** — 태블릿 + 휴대용 감열 프린터로 어르신 댁에서 찍어 그 자리에서 인쇄·전달
- **장소별 무료 갤러리** — 인쇄·공유한 카드가 그 기기 안에 컬러 원본으로 쌓임 (서버·비용 0)
- **맞춤 콘텐츠** — 말씀(랜덤) 외에 **기도제목 직접 입력**(심방·비치용)

### 구현한 것 (링크·스크린샷 — 이미지는 `이미지첨부/` 폴더에)

**① 온마음 말씀사진관 (교회·선교)** → https://onmaeum-song-studio.vercel.app/print.html
**② 굿모닝라이언 행운 사진관 (회사 로비 확장)** → https://baezzanglion.github.io/sponge-intro/lion.html

> "같은 엔진, 다른 콘텐츠" 구조 — 카메라·보정·인쇄 엔진은 하나, 콘텐츠 슬롯만 교체(말씀 ↔ 행운/응원). 온마음 소스 한 곳을 고치면 변환 스크립트로 회사용을 재생성합니다.

**4주차에 새로 구현한 기능**

| 기능 | 내용 | 계기 |
|---|---|---|
| 🎨 컬러 원본 카드 | 인쇄용 흑백 외에 **컬러 카드**를 저장·공유 | 실제 피드백(원본 저장) |
| 🖼 기기내 갤러리 | 인쇄·공유 시 **컬러 원본 자동 보관**, 장소(교회명)별 분리, **비용 0**(IndexedDB) | 감열지 보존 우려 |
| ✍️ 사진 없이 카드 | 촬영이 부담스러운 어르신용 **말씀+이름만** 카드 | 페르소나 거절사유 |
| 🙏 기도제목 직접 입력 | 말씀(랜덤) 대신 **기도제목**을 직접 적어 카드로 (회사용은 💌 메시지) | 실사용 의견 |
| ✨ 곱게 / 🎉 효과 | 피부결 보정 + 꽃가루·반짝이·꽃잎 효과 | 현장 만족도 |
| 🧾 감열지 안내 | "인쇄본은 옅어질 수 있으니 폰에 저장" 안내(화면만, 출력본엔 없음) | 보존 우려 |

- **스택:** 단일 HTML + Vanilla JS(빌드 없음) · GitHub→Vercel/Pages 자동 배포 · Web Bluetooth · getUserMedia · Canvas(Floyd–Steinberg 디더링) · IndexedDB · Web Share API
- **배포 현황:** 평해감리교회(완료·운영 중) / 전의무학교회(설치 예정) / 회사 로비(설치 예정) / 일본 선교(검토)

### 🧭 이번 주에 세운 원칙 — 그리고 안 만든 것
> 만들며 내린 결정을 원칙으로 남깁니다. 다음 확장(전의무학·일본·로비) 때의 판단 기준.

1. **보관은 기기 안** — 서버가 없으면 유출도 없다. 초상권·데이터 우려에 대한 구조적 해답 (갤러리를 클라우드가 아닌 IndexedDB로 만든 이유)
2. **한계는 출력물이 아니라 화면에 적는다** — 어르신 손에 쥐는 카드엔 따뜻함만, "옅어짐" 안내는 운영 화면에만
3. **랜덤이 기본, 직접 입력은 선택** — 어떤 기능을 더해도 어르신의 조작 부담은 한 단계도 늘리지 않는다
4. **같은 엔진, 다른 콘텐츠** — 원본(print.html) 한 곳만 고치고, 회사용은 변환 스크립트로 재생성한다 (두 벌 유지보수 금지)

**안 만든 것 (그리고 왜):**
- **클라우드 통합 갤러리** — "본부에서 전 지점 카드 모아보기"는 매력적이지만, 비용과 초상권 정책 리스크가 새로 생긴다. 현장에서 필요가 확인될 때까지 보류
- **300DPI 프린터 전환** — 선명도는 오르지만 전용 프로토콜 재개발이 필요. 옅어짐의 본질은 종이 화학이므로 **고보존 감열지 교체가 먼저**

## 🗣 과제 2. 유저 피드백 받기

### 실제 유저 피드백 (2명 이상)

**① 일본 선교 준비 중인 가족 (실사용 예정자)**
- 좋은 점: "신기하다, 어렵지 않다" — 조작 난이도는 통과
- 아쉬운 점: **화질**, 그리고 **"이미지로 저장할 때 원본(컬러)으로 저장되면 좋겠다"**
- 아이디어: **"수련회 때는 기도제목을 넣어 프린트해 벽에 붙여두면 좋겠다"**
- → **반영:** 컬러 원본 저장/공유 + 기기내 갤러리 + **기도제목 직접 입력** 기능으로 그대로 구현

**② 평해감리교회 현장 (설치·운영)**
- 3주차에 실제 설치 후 운영 중. 사모님·공동체에 피드백 요청.
- 관찰: 즉석 인쇄물의 "그 자리에서 받는" 반응은 좋으나, **감열지가 시간이 지나면 옅어지는** 물리적 한계 확인
- → **반영:** "진짜 보관본은 폰에 컬러로" 이중 구조 + 감열지 안내 문구
- *(사모님·공동체 추가 피드백 수집 중 — 도착하는 대로 반영 예정)*

### 가상 페르소나 피드백 (플러스 알파 — 5인 패널 인터뷰)
> ⚠️ 통계 기반 합성 페르소나 5인의 **가상 반응**. 실제 검증을 대체하지 않으며, 방향을 잡기 위한 사전 단계.

**거절 사유 TOP 4**

| 순위 | 내용 | 규모 |
|---|---|---|
| 1 | **지속운영 인력 부재** — "결국 나한테 다 몰린다 / 우리 교회는 사람이 없다" | 5명 중 4명 |
| 2 | **감열지 한계** — 글씨가 날아감, 옅으면 어르신 눈에 안 보임, 소모품 조달·비용 | 4명 |
| 3 | 어르신이 **사진 찍히기를 부담**스러워함 — "머리도 안 했는데" | 2명 |
| 4 | **초상권·사진 저장 정책 부재** — 법적 책임 + 데이터 관리 | 2명 |

**가장 의외였던 한마디** *(가상 페르소나 · ICT 전공 목사)*
> "감열지는 시간 지나면 글씨가 날아가요. 어르신께 '말씀 담긴 사진'이라고 드렸는데 그게 하얗게 지워지면… 그건 안 드린 것만 못해요."

### 피드백에서 알게 된 것 (그리고 실제로 고친 것)

1. **거절 1위는 기능이 아니라 "누가 계속 돌리나"(운영)였다.**
   → 컨셉을 *주일 상주 키오스크* → **심방 동행형**으로 재해석 (앱은 이미 휴대형이라 포지셔닝·매뉴얼 문제). 인수인계 매뉴얼을 "제품의 일부"로.

2. **감열지 옅어짐(거절 2위 = 가장 의외였던 한마디)을, 마침 그 주에 붙인 갤러리가 정면으로 해결했다.**
   → **컬러 원본 갤러리·공유**로 "즉석본은 감열지, 보관본은 폰에 컬러로". 화면에만 안내 문구 추가.

3. **"어르신이 좋아한다"는 전제는 검증 대상이다.**
   → 페르소나 2명이 "손사래부터 치신다"고 반론 → **사진 없이 말씀/기도제목 카드** 옵션 추가. (단 평해감리 현장에선 반증됐을 수 있어, 실제 검증이 1순위로 남음 — 이 한계를 정직하게 남겨둠)

4. **하드웨어 개선점도 분리해 파악.** 옅어짐 = 종이 화학 → **고보존 감열지**가 답(프린터 그대로). 선명도 = 300DPI 프린터(별도 프로토콜 대응 필요). → 현실적 1순위는 종이 교체.

## 📣 과제 3. SNS 기록 남기기

### 기록 내용 (소회)

이번 주에 배운 건 **"만드는 것보다 검증하는 게 무섭다"**는 것이었다. 3주차까지 "완성했다"고 생각했는데, 가상 페르소나 5명에게 물어보니 1위 거절 사유가 기능이 아니라 **"이거 선교팀 떠나면 누가 계속 돌려요?"** 였다. 뜨끔했다.

가장 신기했던 건, 실제 사용자(일본 선교 준비 중인 가족)의 **"원본으로 저장되면 좋겠다"**는 한마디와, 페르소나 목사님의 **"감열지 글씨가 날아가면 안 드린 것만 못하다"**는 말이 **같은 곳을 가리키고 있었다는 것**이다. 그래서 그날 바로 **컬러 원본을 폰에 남기는 갤러리**를 붙였다. 피드백이 코드가 되는 순간이 짜릿했다.

그리고 "사람들에겐 말씀이 좋지만 심방·비치용엔 **기도제목**이 낫겠다"는 의견을 받아 **직접 적는 모드**를 넣었더니, 같은 엔진이 **회사 로비용(응원 메시지)**으로도 자연스럽게 확장됐다. 하나의 엔진이 교회에선 말씀·기도제목으로, 회사에선 행운·응원으로 쓰인다. 좋은 도구는 결국 **한 곳을 깊게 파면 여러 곳에서 쓰인다**는 걸 배웠다.
