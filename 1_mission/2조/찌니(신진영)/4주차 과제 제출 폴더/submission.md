🎯 과제 1. PRD 기획 및 구현
주요 가치
"질문 하나를, 그 질문에 맞는 오행 전문가가, 2,000자 깊이로 답한다."

일반 사주앱(운세 요약·범용)과 무료 ChatGPT 사이의 화이트스페이스 = 자유질문 × 장문 리포트를 노린다.
계산은 결정론 엔진(사주 4주·십성·대운·신살 등)이 정확히 내고, 서사·판정은 LLM 해석 레이어가 맡는다 → "암산 금지"가 구조로 강제돼 정확도가 담보된다.
차별점 3줄: ① 질문에 맞는 전문가(오행 캐릭터) 배정 · ② 못 보는 건 못 본다고 정직하게 · ③ 질문 하나를 깊게 (다크패턴·가짜 실시간 배제 = "정직함이 후킹").
페르소나
구분	내용
1차 타깃(기획)	점성술 네이티브 — 서구 20~35세, 유료 리딩 구매 경험층. 대표 페르소나 Maya. K-culture 후광·질문형 UX 수렴 진입 확인.
실측으로 드러난 코어	국내 20대 초·콘텐츠 소비층 — 캐릭터/세계관·미니 보완카드가 인스타 스토리 바이럴 자산으로 작동 (가상 피드백 결과).
코어 아님(확인됨)	30대·기혼 — 인생 큰 결정 1회성이라 재구매 동기 희박.
캐릭터 IP	오행 5종 캐스트: Mr. Mo(木)·Miss Fa(火)·Mr. To(土)·Mr. Kim(金)·Miss Soo(水). 유저 명식의 최다 오행 = '내 메인 캐릭터'.
소구 방식
가격 좌표: 건당 단품 $79 — 국내 앱($13)과 인간 리딩($20/질문) 사이. (현재는 결제 없는 무료+레이트리밋으로 임시 운영)
퍼널: 가입 → 무료 미니리딩(성격·명식) → 질문당 유료 리포트. 페이월 경계 "성격 무료 · 시기해석 유료"는 경쟁사(할마카세)로 시장 실증된 지불 경계.
3지점 미리보기: 랜딩 샘플 전문 공개(품질 증명) → 미니리딩 말미 개인화 티저(훅) → 결제 직전 스펙 고정(기대치 고정·환불 예방).
바이럴: 공유 카드 + 크리에이터 제휴 + SEO 복리 + 캐릭터 숏폼.
리포트 규격: 5섹션 + "전문 분석 + 쉽게 말하면" 2층 구조, 3,500~5,500자.
구현한 것
상태: 실제 상용 서비스로 Cloud Run에 배포·운영 중 (프로덕션 saju-api-v2, asia-northeast3 / DB Supabase Postgres 영속화 검증 완료).

엔진: v0.7 → v0.16.4 (라이브). 신강약·용신 / 합충형파해+궁위 / 신살 확장+십이신살 / 육친 / 격국 재료 / 연애 성향 아키타입 / 발생축·종왕·통관. 4주 계산(v0.6)은 동결 무수정.
서비스 레이어: FastAPI + SQLAlchemy 2.0 — 익명 쿠키 세션·질문·리포트 상태기계·결제(목업 어댑터)·레이트리밋(유저/전역 일일 한도)·이벤트/LLM콜 원장.
화면 14종(정적 HTML): index(랜딩)·birth(출생정보)·mini(무료 미니리딩)·ask(질문)·generating·report(리포트)·sample·gunghap(궁합)·calendar(운세 캘린더)·card(공유 카드)·style-guide·terms·privacy·engine-check(QA).
성장 기능: 궁합(/api/gunghap)·운세 캘린더(/api/calendar)·연애 성향 아키타입·공유 카드.
관리자 콘솔: 이벤트 원장·LLM 호출 원장(원가 박제)·운영 대시보드(/admin/, ADMIN_TOKEN 게이트).
테스트 게이트: 10 스위트 59케이스 전부 통과. 골든 4 원칙 유지.
미결/공백: 도메인 미연결, 인증/결제는 목업(현재 결제 없는 무료+레이트리밋 임시 운영).

실제 유저 피드백 (2명 이상) — ⚠️ 아직 수집 필요
정본 문서에 **"실제 인터뷰가 1순위 데이터 공백"**으로 명시돼 있고, 프로젝트 기록에 실제 유저 피드백이 없습니다. 이 칸은 지어내지 않고 비워둡니다. 아래 스크립트로 2명만 받으면 바로 채워집니다.

빠른 수집 가이드 (5~10분/인) — 가상 피드백에서 나온 위험 지점을 실제로 검증:

(랜딩~미니리딩 보여주고) "이게 무슨 서비스 같아요? 뭘 해주는 것 같아요?" → 5초 안에 가치가 전달되나
"출생시각 정확히 아세요?" → 초입 최대 이탈원 검증 (모르면 어떻게 행동?)
(질문 입력) "지금 진짜 물어보고 싶은 거 하나 적어보세요" → 자유입력 자연스러움 / 다중질문 욱여넣기
"질문에 맞는 전문가가 답한다 vs 그냥 사주 다 봐준다 — 뭐가 더 끌려요?"

가상 페르소나 피드백 (완료)
스킬 virtual-customer-feedback (NVIDIA Nemotron-Personas-Korea 기반), 세그먼트 A 4인. 원문: docs/customer-feedback-conclusions-20260725.md.

한 줄 결론: 방향(직접 입력 + 기본분석·질문답변 결합 + 오행 전문가 서사)은 2030에 맞다. 다만 ① 질문 배정 순서 ② 무료↔유료 중복 ③ 결제 신뢰(달러·후기) 세 곳이 안 풀리면 각각 이탈·낚임·재탕으로 뒤집힌다.

페르소나	핵심 반응
황혜란	빈 입력창 막막함 + 질문 전에 전문가가 먼저 배정되니(이직 고민에 '돈 전문가' 배치) 첫 화면에서 약속이 깨져 뒤로가기
박현식	"기본 분석"이 미니에서 본 걸 재탕 → "분량 채우기"로 읽힘 → $7 근거 붕괴
최도성	후기(사회적 증거) 0 → "GPT 복붙인지 진짜인지" 판단 불가 → 이탈 / 질문 하나에 몰래 세 개 욱여넣음
(공통)	달러($7) 표기 → "원화 얼마? 수수료? 카드사 문자?" 3초 저항 / 출생시각 모름 = "엄마한테 카톡"하며 탭 이탈 후 증발
피드백에서 알게 된 것 (우선순위순)
[최우선·구조 결함] 순서를 뒤집어야 한다 — 질문을 받기 전에 전문가를 배정하면 5초 테스트의 승리 메시지("질문에 맞는 전문가가 답한다")와 실제 플로우가 어긋난다. → 중립(Kim)으로 받고 질문 판정 후 배정(reassign_notice 문자열 이미 존재).
"다양한 질문 다 답변"은 강점이 아니라 함정 — 무료 ChatGPT와 구분 불가 + 건당 과금과 충돌. 셀링포인트에서 빼고 "질문에 맞는 전문가·못 보는 건 못 본다·하나를 깊게"로.
무료 미니 ↔ 유료 리포트 중복이 $7 근거를 무너뜨린다 — 답변이 주인공, 기본 분석은 '왜 이 답인지' 근거로 뒤에. 목차에 질문답변/근거 분량 비율 노출.
결제 직전 신뢰 붕괴 2종 — 달러 표기(→ 원화 병기)·사회적 증거 0(→ 후기).
출생시각 모름 = 초입 최대 이탈원 — 시각 모름 경로 안내·정확도 영향 설명 보강.
코어 타깃은 20대 초 콘텐츠 소비층 — 캐릭터/세계관·미니 보완카드가 바이럴 자산. 30대 기혼은 코어 아님.
⚠️ 주의: 가상 피드백은 실제 검증의 전 단계다. 진짜 고객 인터뷰·결제·퍼널 로그를 대체하지 않는다. (위 '실제 유저' 칸 2명 채우기가 다음 액션)
