# 티키타 (Tikitah) — 부담 없는 커피챗 AI

> **"뭐부터 말해야 할지 몰라도 괜찮아. 네 얘기, 판단 없이 들을게."**

**챗GPT는 '물어보는 도구', 티키타는 '물어봐주는 서비스'.**
배경 설명 없이 뱉을 수 있는 유일한 자리 — 그리고 그 말이 *나를 비추는 카드*로 쌓인다.

- **과제:** 스폰지클럽 2기 · 과제 1 「PRD 기획 및 구현」
- **작성:** Semi Park · 2026-07
- **이름 뜻:** '티키타카'에서 착안 — AI가 먼저 말을 건네며 퐁당퐁당 주고받는 대화의 합(合).

## 바로 써보기

1. **`index.html`을 브라우저로 열기** (더블클릭). 설치·서버·로그인 전부 불필요.
2. 상황 카드 하나 고르기 → 질문 따라 대화 → **정리 카드** 받기 → 보관함에 쌓임.
3. 기본은 **체험 모드**(미리 짠 흐름, 키 없이 바로 작동). 설정(⚙)에서 Claude API 키를 넣으면 **실제 AI 대화**로 전환.
4. 시작할 때 **말투(반말/존댓말)** 를 고르고, 설정에서 언제든 변경.

> 대화는 이 브라우저 안에만 저장돼요(무백엔드). 광고도, 판매도 없습니다.

## PRD 요약 (6요소)

### 1. 문제 — 누가, 언제, 무엇을 못 하나
30대가 되면 친구들이 육아 트랙과 커리어 트랙으로 갈라지며 **고민을 나눌 상대가 사라진다.** 처음 겪는 고민은 혼자 생각해도 안 풀리는데, 능동적으로 같이 생각해줄 존재가 없다. 대체재는 다 어딘가 비어 있다 — 콘텐츠는 수동적, 친구는 맥락 설명이 피곤, 커뮤니티는 내향형에게 부담, 상담은 무겁고, 챗GPT는 빈 화면 앞에서 뭘 물어야 할지 모른다.

### 2. 페르소나 — 누구를 위해
**주요 타깃: 30대 여성, 커리어 지속 중, 내향적.** 주변 친구는 대부분 육아 트랙이라 커리어 고민을 나눌 상대가 없다. *"이런 거 물어볼 사람이 없네.", "콘텐츠는 많이 보는데 왜 내 삶은 그대로지?"* (확장 페르소나 5인은 PRD 참고 — 커리어/자녀결정/육아/기록·성장/익명필요)

### 3. 주요 가치 — 무엇을 지키나
> **배경 없이 뱉을 수 있는 유일한 자리 → 그 말이 나를 비추는 거울로 쌓인다.**

핵심은 **"배경 없음"이 한계가 아니라 기능**이라는 것. 친구는 나를 알기에 판단하지만("너 원래 그러잖아"), 티키타는 나를 모르니 구조적으로 판단이 불가능하다. 그래서 처음 겪는 고민을 날것으로 꺼낼 수 있다. 획득은 *감정적 배출*("그냥 뱉고 싶어서"), 유지는 *정리+쌓임*으로 분리 설계.

### 4. 핵심 기능
- **AI가 먼저 질문** — 빈 채팅창 대신 상황 카드로 시작
- **대화 중엔 질문만, 답은 카드에서** — 조언하지 않고 스스로 말하게(소크라테스식)
- **7턴 진행 구조** — 진행률 표시, "정리해줘" 상시, 짧게 끝내도 카드는 나옴
- **정리 카드** — 한 줄 요약 + **내가 한 말 인용**("이건 네가 한 말이야") + 다음 생각거리(질문형)
- **보관함** — 카드가 시간순으로 쌓여 "내 생각의 기록"
- **말투 선택**(반말/존댓말) · **배경 안 물음** · **완전 비공개**

### 5. 성공 기준 — 행동으로
- 한 번 쓴 사람이 **다른 고민으로 다시 온다** (재방문 = 신뢰)
- 대화가 **7턴 완주**로 이어지는 비율
- 1인당 **정리 카드 누적 수**

### 6. 범위 — 만들 것 / 안 만들 것
- **MVP(포함):** 위 핵심 기능 전부, 브라우저 저장
- **제외(2.0):** 사람 매칭 · 태그 필터·성장로그 뷰 · 로그인/기기이전 · 관리화면 · 심리 진단/점수화 · 커뮤니티

## 대화 설계 핵심 (심장)

- **7턴 감정 여정:** 막연함 → 구체적 장면 → 감정 → 그 밑의 생각 → 재구성 → 진짜 원함 → 스스로 한 줄 정리 (CBT·소크라테스식 프레임 차용, 진단·치료 아님)
- **조언 금지 강제:** 매 턴 `공감 한 마디 + 질문 하나`, 되비추고 되묻기(reflect→ask), 금지 표현 리스트로 통제
- **정리 카드 규칙:** "내가 한 말"은 반드시 사용자 발화에서 추출(AI가 지어내지 않음) = *"내가 답을 냈다"* 느낌의 핵심 장치
- **안전 가드레일:** 위기 신호 시 질문 규칙을 멈추고 전문 도움 안내 (치료 포지션 아님)

→ 상세 규칙과 **복붙용 시스템 프롬프트 2종**(대화용/카드생성용)은 `conversation-design-coffeechat.md`.

## 장기 비전 (범위 밖, 방향만)

> 혼자(AI) → **또래(P2P)** → **검증된 상담(유료 검토).** 각 단계는 앞 단계가 데이터로 검증돼야 열린다.

- **단계 1 (무료):** 쌓인 카드(고민의 결)로 **부담 없이 비슷한 사람과 연결** — 내가 먼저 사람을 찾지 않는다.
- **단계 2 (유료 검토):** 매칭 대화의 만족도·빈도가 임계를 넘으면, **검증된 사람이 고민을 풀어주는 대화**(온라인 챗·전화, 온라인 상담 모델)로.
- **솔직한 리스크:** "상담/치료" 포지션으로의 드리프트(책임·자격), "검증"의 정의, 프라이버시 충돌, 양면시장 운영 무게 — PRD에 명시.

## 만든 과정 (기획 → 구현 → 검증 → 개선)

1. **기획:** 가치 정립 → 페르소나 5인 → 서비스 구조(허브=정리카드) → 기능 정의 → IA·와이어프레임 → 7턴 대화 설계
2. **구현:** 와이어프레임 + 프롬프트를 단일 HTML 웹앱으로 (무백엔드, 체험 모드 + 옵션 실제 AI)
3. **가상 고객 피드백:** 통계 기반 합성 페르소나 4인 패널 인터뷰
4. **개선:** 피드백 반영 — "왜 무료·데이터 안 판다" 명시, "짧게 끝내도 됨" 안내, **말투(반말/존댓말) 선택** 추가

*본 MVP는 브라우저에서 전체 흐름(상황카드 → 7턴 대화 → 정리 카드 → 보관함 누적, 반말/존댓말)을 검증 완료.*
