## 🎯 과제 1. PRD 기획 및 구현
> 주요 가치 · 페르소나 · 소구 방식을 담은 PRD → 구현까지

### 한 줄 요약
챗GPT는 **"물어보는 도구"**지만, 티키타는 **"물어봐주는 서비스"**다. 질문할 줄 몰라도, 고민이 정리 전이라 어수선해도 — AI가 먼저 질문을 던지고, 대화가 끝나면 **내가 한 말로** 정리 카드를 만들어준다.

- **주요 가치:**
  > **배경 없이 뱉을 수 있는 유일한 자리 — 그리고 그 말이 나를 비추는 거울로 쌓인다.** 한 단어로: *"설명 안 해도 되는 대화 자리."*

  핵심은 **"배경 없음"이 한계가 아니라 기능**이라는 것. 친구가 판단하는 건 나를 알기 때문("너 원래 그랬잖아")인데, 티키타는 나를 모르니 구조적으로 판단이 불가능하고, 그래서 처음 겪는 고민을 덜 검열하고 꺼낼 수 있다. 이 서비스의 대화가 지켜야 할 단 하나 → **"대화 중엔 질문만. 답은 카드에서."** AI가 조언하지 못하게 막는 장치들이 규칙 대부분이다. (조언 금지, 판단 금지, 한 번에 질문 하나, 반영하고 되묻기 reflect→ask)

- **페르소나:**
  > **30대 여성, 커리어 지속 중, 내향적.** 주변 친구는 대부분 육아 트랙이라 커리어 고민을 나눌 사람이 없고, 커뮤니티·네트워킹은 부담스럽다. *"이런 거 물어볼 사람이 마땅찮다."* / *"콘텐츠는 많이 보는데 정작 내 삶엔 그대로 쓰지?"*

  대체재가 다 어딘가 비어 있다 — 콘텐츠는 수동적, 친구는 맥락 설명이 피곤, 커뮤니티는 내향인에게 부담, 상담은 무겁고, 챗GPT는 빈 화면 앞에서 뭘 물어야 할지 모른다. **그 사이 어딘가가 비어 있다.**

- **소구 방식:**
  - **AI가 먼저 질문** — 빈 채팅창 대신 **상황 카드**("요즘 커리어가 막막해요" 등 4개) 하나 고르면 대화 시작.
  - **7턴 대화 설계** — 막막함 → 구체적 장면 → 감정 → 그 밑 생각 → 재구성 → 진짜 원함 → 스스로 한 줄 정리. (CBT·소크라테스식 화법을 *형태만* 차용, 진단·치료 아님)
  - **정리 카드** — "이건 네가 한 말이야"에 **AI가 아니라 사용자 발화에서 뽑은 문장**을 인용. *"AI가 답을 줬다"*가 아니라 *"내가 답을 냈다"*고 느끼게 하는 재방문(신뢰) 장치.
  - **반말/존댓말 말투 선택**(가상 고객 피드백 반영) · **배경 안 물음** · **감정 안전 가드**(위해 신호 시 질문 멈추고 전문 도움 안내).

- **구현한 것 (링크·스크린샷 — 이미지는 `이미지첨부/` 폴더에):**

  **백엔드 없이 브라우저만으로 도는 단일 HTML MVP** (`index.html`). 설치·서버·로그인 전부 불필요, 더블클릭이면 바로 뜬다.
  - **체험 모드(기본):** API 키 없이도 미리 짜둔 7턴 흐름으로 전체 경험(상황카드 → 7턴 대화 → 정리 카드 → 보관함)이 도는 데모.
  - **실제 AI 모드(선택):** 설정에서 Claude API 키를 넣으면 진짜 대화로 전환. 키는 이 브라우저에만 저장(무백엔드).
  - **화면 흐름:** 서비스 소개(인트로) → 상황 카드 홈 → 7턴 채팅(진행률 7점 표시·"정리해줘" 상시 노출) → 정리 카드("오늘 네가 한 말, 정리해봤어") → 보관함("내 생각의 기록").
  - **말투 반말/존댓말 스크립트를 트랙별로 분리**해 넣었고, 정리 카드는 JSON 스키마로 강제해 사용자 발화 인용을 뽑게 설계.

  *로컬 단일 페이지라 공개 링크는 없음 — `index.html` 더블클릭으로 실행. 웹 배포는 다음 할일.*

  **함께 제출하는 문서:**
  - `PRD-coffeechat-ai.md` — 전체 PRD(문제·페르소나·가치·기능·성공기준·범위·장기비전)
  - `conversation-design-coffeechat.md` — 7턴 대화 설계 + 복붙용 시스템 프롬프트 2종(대화용·카드생성용)
  - `README.md` — 요약(PRD 6요소 + 실행법)

- **실제 유저 피드백 (2명 이상):** 🔜 *아직 못 받음 — 추후 보완 예정.*
- **가상 페르소나 피드백:** 통계 기반 합성 페르소나 4인 패널 인터뷰를 돌렸다.
- **피드백에서 알게 된 것:**
  - **"낯선 상대인데 반말이 불편하다"** → 온보딩·설정에서 **반말/존댓말을 사용자가 선택**하게 확장. (기본값은 '반말', 존댓말 선택 시에도 감정 안전·질문만·판단 금지 원칙은 그대로.)
  - **"7턴이 부담될 수 있다"** → **"짧게 끝내도 된다"**를 인트로·안내에 명시하고, 언제든 '정리해줘'로 빠질 수 있게 안내 문구 보강.
  - **"이거 무료 맞나? 데이터 팔리는 거 아냐?"** → *"광고도 판매도 없고, 대화는 이 브라우저에만 남는다"*를 인트로에 명시.

### 💡 알게 된 인사이트
- **"기능"이 아니라 "관점"이 서비스를 만든다.** 같은 챗 인터페이스라도 *"내가 묻는다" → "AI가 물어봐준다"*로 뒤집으니 완전히 다른 자리가 된다.
- **"배경 없음"을 한계가 아니라 가치로 재정의**한 게 이 기획의 핵심이었다. 나를 모르니 판단이 불가능하다 = 처음 겪는 고민을 검열 없이 꺼낼 수 있다.
- **AI에게 조언을 시키지 않는 게 제일 어려웠다.** LLM은 자꾸 도와주려 하는데, 그걸 막는 게(질문만·되묻기·판단 금지) 이 서비스의 난이도이자 정체성이다.
