# 4주차 — 기획·구현 → 검증 → 기록 🧪

> 프로덕트: **한눈에** — 아이폰의 모든 캘린더(구글·iCloud·가족·공휴일)를 한 화면에서 보고 관리하는 아이폰 전용 캘린더 앱.

## 🎯 과제 1. PRD 기획 및 구현
> 주요 가치 · 페르소나 · 소구 방식을 담은 PRD → 구현까지

- **주요 가치:** 아이폰에 흩어진 여러 캘린더(회사 구글 · 개인 iCloud · 가족 · 공휴일)를 **한 화면에서** 보고, **보고 싶은 것만 골라** 본다. 데이터는 **기기 안에만 저장(서버 없음)**. 한국형(공휴일·음력·나만의 휴일)·오늘 강조·자연어/음성 빠른 입력("내일 3시 치과").
- **페르소나(초기 타깃):** 회사+개인 캘린더가 앱마다 따로 놀아 불편한 **30–40대 직장인/워킹맘**. (인접: 1인 전문직, 시니어)
- **소구 방식:** 애플 기본 캘린더 대비 **"보고 싶은 것만 한눈에 + 내 폰에만 저장 + 한국 달력답게(공휴일·음력)"**. "말/글로 바로 넣는 빠른 입력."
- **구현한 것:** EventKit 기반 아이폰 앱 **v3.0.0** (Capacitor 8, `@ebarooni/capacitor-calendar`). 실기기에서 **캘린더 권한 → 구글·iCloud·공휴일 목록·색 표시 → 표시 캘린더 선택 → 일정 CRUD(선택 캘린더 저장·색 반영) → 반복 → 완료(✓) → 나만의 휴일 → 공휴일 표시**까지 동작. 시뮬레이터·실기기 빌드 성공, TestFlight 준비 중.
  - 개발 진행 중 이슈(첫 로딩 속도)를 실사용에서 발견 → EventKit 조회 병렬화·캐시·로더 개선 중.

## 🗣 과제 2. 유저 피드백 받기
> 실제 2명 이상 + 플러스 알파로 가상 페르소나

- **실제 유저 피드백 (2명 이상):** ※ 실기기 배포(TestFlight) 후 수집 예정 — 본인·가족 실사용 테스트 진행 중. (아래는 플러스 알파 **가상 페르소나** 피드백)

- **가상 페르소나 피드백:** `virtual-customer-feedback` 스킬(NVIDIA Nemotron-Personas-Korea, 한국 인구통계 기반 합성 페르소나) 활용. 타깃 A·B·C를 아우르는 **패널 4명** 인터뷰 + 가격·필수기능 라운드.
  - **만난 고객:** 황혜란(33·경리·인천), 최연옥(50·치과 원장·서초), 김세원(34·1인 사업자·안산), 안상식(73·퇴직·목동)
  - **① 패널 인터뷰 (안 쓸 이유 위주):**
    - 공통 거절 이유: **첫 로딩이 느림**("3초 글랜스가 캘린더의 본질인데 치명적") / **"기본 캘린더도 구글 연결하면 통합됨 — 굳이 앱 하나 더?"** / **"모든 캘린더를 읽는다"는 프라이버시 불안**(전문직).
    - 갈린 반응: 통증 실재한 **직장인(황혜란)**이 최고 반응 → 1순위 타깃. 의외로 **치과 원장(최연옥)은 "통합"이 아니라 "분리(병원/개인)"를 원함** → 통합 메시지론 안 팔림.
  - **② 가격·필수기능:**
    - **월 구독은 광범위 거부**(황혜란·김세원·안상식). 최연옥만 "가치 있으면 월 3천 원대" 조건부.
    - → 현실 모델 = **무료 기본 + 일회성 언락(₩3,300~5,500)**. **무료+광고는 차별점(프라이버시·빠른 글랜스)을 스스로 훼손** → 비추천.
    - **가장 강하게·공통으로 나온 필수 기능 = 홈 화면 위젯**("앱 안 열고 오늘이 보이는 것"이 '한눈에'의 핵심 값). 그 외: 표시 캘린더 **그룹 원터치 전환(병원↔개인)**, 앱 잠금(Face ID).

- **피드백에서 알게 된 것:**
  1. **로딩 속도**가 가상 고객에게도 **1순위 거절 이유** → 출시 최대 리스크. 3초 글랜스 수준 마무리가 우선.
  2. 메시지를 **"다 합쳐 보여줌" → "보고 싶은 것만 한눈에 + 내 폰에만 저장"**으로 교정. 1순위 타깃도 전문직이 아닌 **직장인/워킹맘**으로 좁힘.
  3. 수익모델은 **무료 출시 → 위젯·필터·잠금 묶은 일회성 언락**. 월구독·광고는 접음.
  4. **홈 화면 위젯**(네이티브 WidgetKit)이 기본 앱과의 차별점이자 일회성 언락의 핵심 가치 → 로딩 다음 우선순위.

> ⚠️ 가상 피드백은 실제 검증의 전 단계입니다. 방향 감각용이며, 가격·"쓰겠다"는 실제 고객의 결제·잔존으로만 확정됩니다.
