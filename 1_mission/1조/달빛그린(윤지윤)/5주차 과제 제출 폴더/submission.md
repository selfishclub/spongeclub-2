## 🎯 과제 1. 구현, 그 다음의 것

![과제 1 안내](https://github.com/selfishclub/spongeclub-2/raw/main/_meta/week5/mission1.png)

> 만드는 건 끝났는데 — 그 다음이 진짜 시작이에요 (답이 안 나와 있어도 OK, 고민을 꺼내놓는 것 자체가 과제)
- **지금 걸려 있는 고민 하나:**
  이 서비스의 킬러 기능은 "그 시기 그 목적지를 다녀온 여행객들의 실제 옷차림 사진"인데, 인스타그램은 API가 막혀 있고 핀터레스트·구글 검색 결과는 시기가 안 맞거나 광고성 이미지가 섞여서, 현재 구현은 '검색 결과·링크 보여주기' 수준에 머물러 있다. 차별점이라고 정의한 기능이 실제로는 가장 약하게 구현된 상태다.
- **그게 왜 고민인지 (무엇이 걸리는지):**
  이 기능이 약하면 나머지(날씨 요약 + 코디 추천 + 옷장 플래너)는 기존 날씨 앱과 메모의 조합과 크게 다르지 않아서, "다음 버전을 만들 이유"가 흔들린다. 그리고 타인의 사진을 서비스 화면 안에 표시하는 방식은 저작권 문제가 있어, 기술적으로 풀어도 권리 문제가 남는다.
- **어떻게 풀어볼 생각인지:**
  첫째, 다음 실제 여행 1회에 이 프로토타입을 그대로 써보고 "링크 수준의 레퍼런스로도 옷 결정에 충분한가"를 성공 기준(안 입은 옷 감소, 추천 코디 착용률)으로 검증한다. 부족하다고 판단되면 둘째, Claude 비전으로 검색 결과 이미지의 시기·상황 적합성을 필터링하는 레이어를 붙여 품질을 올리고, 셋째, 장기적으로는 사진을 '수집'하는 대신 여행을 다녀온 사용자가 자기 옷차림을 제보하는 구조(권리 문제 원천 해소)를 검토한다.
- **필요한 게 있다면 무엇인지:**
  Google Custom Search API 키와 무료 쿼터 한도 확인, 이미지 필터링용 Claude API 호출 비용 감각, 그리고 외부 이미지·임베드 표시의 저작권 경계에 대한 실무 가이드(개인 도구일 때 vs 외부 공개 시).

## 🏁 과제 2. 구현 마무리 + 실제 유저 피드백 받기

![과제 2 안내](https://github.com/selfishclub/spongeclub-2/raw/main/_meta/week5/mission2.png)

> 시작할 때 "이번엔 이건 꼭 만들겠다" 했던 것 — 지금 어디까지 왔나요? (스폰지클럽 내 유저피드백 모집 가능)
- **최종 완성한 것 (지금 어디까지):**
  아침 기상과 비폭력대화(NVC)를 결합해서, 매일 카드를 뽑고 상상을 발화하면 그게 쌓여 나를 주인공으로 한 자서전이 되는 서비스 **'모닝챕터'**를 만들고 싶었습니다. PRD 6블록 확정, 핵심 화면 2종 프로토타입(HTML), LLM 프롬프트 3종, 실무 콘텐츠(어휘집·폴백 카드덱)까지 — 기획부터 프롬프트 검증까지 한 사이클을 완주했습니다.
  - PRD v0.2 — 문제정의부터 성공기준까지 6블록 + 알람/카드/서재/갈등모드 상세 스펙
  - 아침 세션 프로토타입 — 알람 끄기 → 카드 5장 뽑기 → 발화 → 느낌·욕구 확인 → 서재(에피소드가 쌓여 한 권의 책으로 자라는 구조)
  - 갈등 자기공감 모드 프로토타입 — NVC 6단계(자칼 쇼 → 관찰 → 느낌 → 욕구 → 상대 추측 → 부탁) + 안전 전환 화면(자·타해 신호 감지 시 상담 연결)
  - LLM 프롬프트 3종(에피소드 생성, 챕터 엮기, 갈등 모드) — 직접 시뮬레이션 검증까지 완료, 버그 1건 발견·수정
  - 카드 폴백 덱 30장, 느낌·욕구 닫힌 어휘집(64개) 확정
- **🚀 실제 배포 URL:**
  아직 없음 — 지금은 로컬에서 여는 HTML 프로토타입 단계이고, 실제 서버 배포는 진행하지 않았습니다.
- **결과물 (링크·스크린샷 — 이미지는 `이미지첨부/` 폴더에):**
  - [`90s-flow-prototype.html`](이미지첨부/90s-flow-prototype.html) (아침 세션 + 서재)
  - [`conflict-mode-prototype.html`](이미지첨부/conflict-mode-prototype.html) (갈등 자기공감 모드)
  - [`PRD_모닝챕터_v0.2.html`](이미지첨부/PRD_모닝챕터_v0.2.html)
  - [`storybook-prompt.html`](이미지첨부/storybook-prompt.html) / [`conflict-mode-prompt.html`](이미지첨부/conflict-mode-prompt.html)
- **받은 유저 피드백:**
  아직 없음 — 현재는 가상 페르소나로 시나리오를 시뮬레이션하며 검증하는 단계까지 진행했고, 실제 유저 피드백은 아직 못 받았습니다. 과제에 나온 스폰지클럽 유저피드백 모집을 활용해볼 계획입니다.

## 📣 과제 3. SNS에 남기기

![과제 3 안내](https://github.com/selfishclub/spongeclub-2/raw/main/_meta/week5/mission3.png)

> 구현했던 것들 + 그 다음 단계에 대한 생각 (아끼면 아무 일도 안 일어나요 — 꺼내놓는 순간 가장 많이 남아요)
- **구현했던 것들 (무엇을 / 어떻게 굴러가는지 / 뭐가 달라졌는지):**
  🌙 모닝챕터 — 아침마다 뽑는 카드가 나의 자서전이 되는 서비스

  알람을 끄면 카드 5장이 부채꼴로 펼쳐져요. 한 장 골라 뽑고, 떠오르는 상상을 말하면 느낌·욕구를 가볍게 확인 — 여기까지 90초. 매일 쌓인 짧은 에피소드는 원할 때 '책으로 엮기'로 이어붙여서, 나를 주인공으로 한 자서전이 됩니다.

  관계 때문에 힘든 날을 위한 '갈등 자기공감 모드'도 만들었어요. 판단·비난 먼저 다 뱉고 → 사실만 남기고 → 느낌·욕구 찾고 → 부탁 문장 만들기까지, 비폭력대화(NVC) 6단계를 앱 흐름 그대로 옮겼습니다.

  기획서 한 장이 아니라 실제 프로토타입 2개, LLM 프롬프트 3종, 카드 문구 30장까지 — 아이디어에서 손에 잡히는 것까지 한 바퀴 돌렸습니다.
- **다음 단계 생각 (뭘 더 하고 싶은지 / 남은 것 / 어디로):**
  - 프로토타입 → 실제 배포
  - 진짜 유저한테 보여주고 피드백 받기
  - 온보딩 · 아이콘 다듬기
