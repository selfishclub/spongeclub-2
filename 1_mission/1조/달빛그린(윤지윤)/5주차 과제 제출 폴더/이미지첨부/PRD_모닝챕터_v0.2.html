① 문제 정의

누가 · 언제 · 어떤 상황에서 뭘 못 하고 있는가

비폭력대화(NVC)를 배워 자기 느낌과 욕구를 볼 줄 알게 된 사람이, 아침에 혼자 깨어난 순간 그 알아차림을 둘 곳이 없다.

NVC의 네 번째 단계는 '부탁'이고, 부탁은 상대를 필요로 한다. 그런데 아침 7시엔 부탁할 상대가 없다. 그래서 관찰 → 느낌 → 욕구까지는 도달하는데, 거기서 문장이 끊긴다. 로젠버그는 미충족 욕구를 만나면 애도하라고 했지만, 혼자인 아침에 애도만 반복하면 가라앉기만 한다.

동시에 이 사람은 만드는 일을 한다. 자기 안에서 나오는 재료가 마르고 있다고 느끼고, 요즘 만드는 게 다 어디서 본 것 같다고 생각한다.

두 문제는 같은 문제다. 갈 곳 없는 욕구가 곧 쓰이지 않은 재료다.

지금은 어떻게 버티고 있는가 (대체재)

대체재 무엇을 주는가 왜 부족한가
감정일기 앱 감정 기록·추적 기록하고 끝. 남는 게 데이터뿐
모닝 페이지 아침의 발산 백지 앞이 막막함. 기상 직후 인지부하로 실패율 높음
명상 앱 진정 비우라고 하지, 채우지 않음. 창작으로 이어지지 않음
실물 NVC 카드덱 좋은 질문 혼자 뽑으면 답할 상대가 없어 한 장 보고 멈춤. 축적되지 않음
타로 앱 뽑는 재미 해석이 밖에서 온다. 자기 언어가 자라지 않음

실제 버티는 방식: 카드 사진만 찍어두고 방치 · 노션에 감정 메모 몇 줄 · 알람 5번 스누즈.

② 주요 페르소나

상황으로 좁힌 한 명

감정을 볼 줄은 알게 됐는데, 알아차린 다음이 없는 사람. 만드는 일을 해서, 자기 안이 마르는 걸 무서워한다.

그 사람이 실제로 뱉은 문장

  • "내 욕구가 뭔지는 알겠어. 근데 그래서 뭐 어쩌라는 거지?"
  • "요즘 만드는 게 다 어디서 본 것 같아."

(직업·나이로 정의하지 않는다. NVC 학습 경험이 뼈대, 창작 갈증이 출구다.)

③ 주요 가치 · 소구 방식

이 프로덕트가 지키는 것

알아차린 욕구가 갈 곳을 잃지 않게 한다. 부탁할 상대가 없을 때, 욕구는 이야기가 된다.

페르소나의 언어로 번역한 한 문장

당신의 매일의 상상이 당신의 스토리가 됩니다.

왜 성립하는가 — 근거 3개

  1. 감정 명명 효과(affect labeling) — 감정에 단어를 붙이면 편도체 반응이 줄고 전전두엽이 활성화된다. 느낌 칩 확인 UI가 곧 개입 도구다.
  2. 감정 세분화(emotional granularity) — 감정을 세밀하게 구분하는 사람일수록 정서조절·회복탄력성이 높다. 어휘를 고르는 행위 자체가 훈련이다.
  3. 기상 직후의 발산적 사고 — 수면 관성 구간(N1 경계)에서 인지 수행은 떨어지지만 발산적 통찰은 오히려 올라간다. 아침의 흐릿함은 결함이 아니라 원료다. 단, 같은 이유로 이 구간에 복잡한 선택을 시켜서는 안 된다 → 90초 제약의 근거.

④ 핵심 기능

4-0. 진입점 — 알람은 기본값이지 필수가 아니다

알람을 끄면, 카드 화면(홈)이 나타난다. 알람 해제와 카드 세션은 분리되어 있다.

  • 알람 화면의 버튼은 하나: 알람 끄기
  • 끄고 나면 카드 5장이 부채꼴로 펼쳐진다. 나중에 할게요로 그냥 나가도 알람은 이미 꺼져 있다
  • 알람 설정은 좌상단 아이콘 뒤에 숨긴다 (알람 사용 켜기/끄기, 시각·요일·깨우는 방식·펼치는 카드 수·일요일 긴 카드)
  • 깨우는 방식은 빛 → 소리, 3분에 걸쳐 (soft 기상)

깨우는 방식 상세 — 여명 시뮬레이션

빛이 소리보다 먼저 들어오면 수면 관성이 줄어든다는 근거로 순서를 고정한다.

구간 시간 빛 소리
1 0~90초 화면이 서서히 밝아짐 (밤→여명 그라데이션. 카드 화면의 하늘색 팔레트와 동일) 없음
2 90~150초 계속 밝아짐 아주 작게 시작
3 150~180초 완전히 밝음 들릴 정도까지 서서히 증가
4 180초~ 유지 유지 (끌 때까지)
  • 소리는 알람음이 아니라 자연음. 삐-삐 각성음은 soft 기상과 충돌한다. 물소리·바람·새소리 계열 제공
  • 소리는 설정에서 하나로 고정. 카드나 요일에 따라 바뀌지 않는다 — 예측 가능성이 알람의 역할이지, 매번 다른 소리로 놀라게 하는 것이 아니다
  • 무음모드에서는 진동만. 소리로 무음모드를 우회하지 않는다 — 사용자의 명시적 설정을 존중한다
  • 스누즈는 횟수 제한 없이 자유롭게. 강제로 막지 않는다 — 미룰 권리도 사용자의 것이다 (⑥ 스트릭 금지 원칙과 같은 결)
  • 알람 없이 쓰는 사용자를 위해, 알람 자체를 끌 수 있다. 알람을 꺼도 카드 화면은 홈 화면으로 상시 접근 가능하다

카드 화면(홈)은 상단 좌우에 항상 두 아이콘을 둔다.

  • 좌: 알람 설정
  • 우: 내 서재 (에피소드 · 책으로 엮기)

⚠️ 강요 금지. 카드를 뽑아야만 꺼지는 알람은 NVC 원칙 위반이다. 알람 해제를 세션의 조건으로 걸지 않는다. 카드는 권유이지 관문이 아니다.

4-1. 카드 뽑기 — 5장 중 한 장

한 장을 통보하지 않고 뒷면 5장을 펼쳐 고르게 한다. 타로의 뽑는 재미가 여기서 나오고, 고르는 행위 자체가 "오늘의 카드는 내가 선택한 것"이라는 소유감을 만든다.

  • 뒷면만 보이므로 내용으로 고르는 게 아니다 — 우연이되 내 손으로 뽑은 우연
  • 고른 카드는 가운데로 나와 뒤집히고, 나머지는 조용히 사라진다
  • 뽑은 뒤 읽는 시간에 제한이 없다. 다 읽고 내 생각 말하기를 눌러야 넘어간다

4-2. 아침 세션 — 시간에 허덕이게 하지 않는다

90초는 목표가 아니라 바닥이다. "말이 안 나오는 날에도 이 정도면 끝난다"는 뜻이지, 그 안에 끝내라는 뜻이 아니다.

따라서 UI에서 시간을 전부 지운다 — 카운트다운 없음, 남은 시간 표시 없음, 자동 전진 없음. 발화 시간만 카운트업으로 보여준다 (압박이 아니라 기록).

원칙: 고르게 하지 말고, 확인만 시킨다. 목록에서 찾게 하는 순간 아침에 실패한다.

# 구간 사용자가 하는 일 넘어가는 방법
0 알람 알람 끄기 버튼
1 카드 고르기 · 읽기 5장 중 1장 선택, 읽기 (시간 자유) 버튼
2 상상 발화 말하기 시작 / 멈추기 직접 조작, 시간 무제한 버튼
3 느낌 확인 칩 탭 (기본 3개 선택됨) 버튼
4 욕구 확인 칩 탭 (기본 2개 선택됨) 버튼

지켜야 할 인터랙션 규칙

  • 자동 전진 절대 금지. 어떤 단계도 저절로 넘어가지 않는다. 사용자가 누르지 않았는데 화면이 바뀌면 불안정해진다.
  • 화면당 결정 1개. 스크롤·검색·타이핑 전면 금지.
  • 발화는 사용자가 시작하고 사용자가 멈춘다. 멈췄다가 이어서 말하기도 가능.
  • 기본값을 미리 켜둔다. 칩은 아무것도 안 해도 그대로 저장된다. 교정은 선택.
  • 틀렸을 때: 다른 느낌 보기 → 후보 3개 추가. 전체 목록은 3뎁스 뒤에 숨긴다.
  • 탈출구: 나중에 할게요 (카드 전), 오늘은 그냥 카드만 (발화 전). 언제든 빠질 수 있다.
  • 암전 없음. 기상 직후에 보는 화면이므로 화면을 끄지 않는다.
  • 진행 표시는 시간이 아니라 단계. 상단 점 5개 + 배경 하늘이 밤 → 여명 → 아침으로 밝아진다.

관찰·부탁까지 가는 확장 세션은 **일요일 '긴 카드'**로 분리한다.

4-3. 카드 생성 — 매일 LLM 생성 + 품질 하한 보장

a. 슬롯 고정 — 백지를 주지 않는다. 무엇을 물을지는 시스템이 먼저 정하고, LLM은 문장 표면만 만든다.

욕구 계열(9) × 질문 유형(A/B/C) × 시간축(과거/지금/가정)

b. 질문 유형 3종 (실물 카드 3장 분석에서 추출)

유형 어미 하는 일 예
A. 위치찾기 ~무엇인가요 / 있나요 기억 소환 "어떤 이의 지속적인 사랑이 당신과 함께하고 있나요?"
B. 반사실 ~하면 어떻게 될까요 시뮬레이션 = 상상 엔진 "더 좋은 것을 찾는 걸 멈추면 어떻게 될까요?"
C. 장면확장 그때 공기는 어땠나요 감각 묘사 유도 (신규 — 발화량을 늘리는 축)

c. 문장 문법 (린터 규칙)

1. 욕구 라벨 단어 포함        → 탈락
2. 부정 전제(없/못/부족)       → 탈락
3. 조언 어미(해보세요/하는 게)  → 탈락
4. 질문 2개 이상              → 탈락
5. 15~35자 이탈               → 탈락
6. 예/아니오로 닫힘           → 탈락
7. 최근 14일 카드와 유사도 0.8↑ → 탈락

d. Best-of-5 + 폴백 덱 — 매일 5장 생성 → 린터 통과분 중 개인위키 기반 1장 선택 → 전부 탈락 시 안전 덱 30장에서 뽑기. 품질 하한이 구조적으로 보장된다.

e. 사후 학습 루프 — 카드별 (발화 길이 / 느낌 칩 교정률 / 이탈률)을 점수화. 고득점 카드는 씨앗 카드로 승격해 다음 생성의 few-shot에 재투입.

4-4. 에피소드와 책 — 매일 쌓이고, 원할 때 엮인다

서사적 정체성(narrative identity). 사람은 흩어진 경험을 이야기로 엮어야 "나는 누구인가"라는 감각을 갖는다. 삶이 이야기가 되는 게 아니라, 이야기가 있어야 삶이 하나로 느껴진다. 이 서비스가 하는 일은 매일 아침 나를 인터뷰하는 것이고, 그 인터뷰가 쌓여 결국 나를 주인공으로 한 자서전 / 소설이 된다.

그래서 "매주 일요일 자동 완결"은 이 가치와 맞지 않는다. 자서전에는 마감이 없다. 구조를 다음으로 바꾼다.

  • 매일의 상상 → 서재에 쌓이는 짧은 에피소드 하나 (제목 + 3~5문장)
  • 사용자가 원할 때, 에피소드 여러 개를 골라 책으로 엮기
  • 엮은 결과는 하나의 진행 중인 책에 새 챕터로 흡수된다. 매번 새 책이 생기는 게 아니라, 같은 책이 챕터를 더하며 자란다 — 첫 엮기의 제목이 책 제목이 되고, 이후 엮기는 그 책에 챕터 2, 3…으로 쌓인다
  • 강제 주기 없음. 매주 아무것도 안 엮어도 실패가 아니다 (스트릭 금지 원칙과 동일한 이유)

대원칙 — LLM은 작가가 아니라 편집자다

사용자가 말하지 않은 사건·인물·장소를 하나라도 지어내면 "내 이야기"가 아니라 "AI 소설"이 된다. 사람은 자기 것만 다시 본다. LLM이 하는 일은 네 가지로 제한한다.

  1. 발화에서 에피소드 제목·요약 추출
  2. 엮을 때 에피소드 사이 순서 재배치 · 연결어 삽입
  3. 반복 등장한 모티프 발견 (장소 · 사물 · 인물 · 감각)
  4. 구어체 문장 다듬기

새 사실 추가 금지. 이 제약이 곧 품질이다.

에피소드 (매일 생성되는 단위)

항목 내용 규칙
제목 사용자 발화에서 그대로 뽑은 구절 창작 금지
본문 3인칭, 3~5문장 짧게. 장면 하나만
태그 그날의 욕구 계열 (내부용) 목록 화면에서만 노출, 본문엔 없음

3인칭인 이유. 자기 경험을 3인칭으로 재구성하면 정서적 거리두기(self-distancing)가 생겨 정서조절에 도움이 되고, 소설처럼 읽히는 효과도 커진다. "그는 물가에 앉아 있었다."

책으로 엮기 (사용자가 요청할 때만)

  • 서재에서 에피소드를 다중 선택하고 책으로 엮기
  • 산출물은 하나의 챕터: 선택된 에피소드들을 반복 모티프로 이어붙인 짧은 글 + 되비추는 쪽(관찰, 패턴) + 욕구 각주
  • 화자 분리 유지: 본문(3인칭 에피소드)과 되비추는 쪽(주어 없는 중립 서술)은 다른 목소리. 같은 목소리가 관찰까지 하면 자기 심판이 된다
  • 되비추는 쪽 규칙: 관찰은 횟수 기반, 평가어(많다/적다/자주/유난히) 금지, 충족된 패턴을 반드시 함께 낸다
  • 본문에 욕구 라벨 금지 — 라벨은 각주에만
  • 챕터가 너무 짧으면(2개 미만 선택 시) 엮기 비활성화 — 억지로 만들지 않는다

편집 가능 — raw / episode 레이어 분리

사용자는 에피소드·챕터의 문장 수정까지 가능하다. 단 데이터가 오염되면 안 된다.

  • raw 레이어(불변): 원본 발화 텍스트 + 사용자가 고른 느낌·욕구 칩. 모든 통계는 여기서만 계산된다.
  • episode/chapter 레이어(가변): 그 위에 얹힌 문장. 자유롭게 고칠 수 있다.
  • 사용자가 고친 문장 자체가 다음 생성의 문체 학습 신호가 된다 — 다른 앱이 복제할 수 없는 루프.

톤 기본값은 되비추기(reflection). 진단·평가·조언 어휘는 금지어 목록으로 관리한다.

4-4b. 갈등 자기공감 모드 — 아무 때나 여는 문

아침 카드가 상상을 여는 도구라면, 이건 정리가 필요한 순간을 위한 도구다. 관계에서 힘든 일이 있을 때, 사람 대신이 아니라 틀 대신 해준다 — 화자는 끝까지 "나"이고, 앱은 빈칸만 잡아준다. ⑥에서 자른 AI 버디 의인화가 여기로 되돌아오지 않도록 주의한다.

진입 위치: 내 서재 옆 탭. 알람과 무관하게 언제든 연다.

NVC 자기공감 6단계

단계 하는 일
0. 자칼 쇼 판단·비난을 그냥 다 뱉기 — 여기부터 시작한다. 바로 "느낌이 뭐예요"라고 물으면 못 한다
1. 사실만 남기기 평가를 걷어내고 관찰만. "그가 무시했다" → "3일간 답이 없었다"
2. 가짜 느낌 걸러내기 "무시당한 기분"은 느낌이 아니라 해석 — "몸에서 느껴진 건요?"로 되묻는다
3. 느낌 고르기 칩에서 확인 (아침 카드와 동일 어휘집)
4. 욕구 고르기 전략과 분리. "그가 연락해주는 것"(전략) → 연결 · 예측 가능성(욕구)
5. 상대 추측 (선택) 그 사람의 느낌·욕구는 무엇이었을까
6. 부탁 문장 (선택) 강요 아닌 부탁 — 거절 가능해야 부탁

산출물 — 둘 다 낸다

  • 나만 보는 정리: 사실 → 느낌 → 욕구가 정리된 한 장. 기본값
  • 보낼 수 있는 문장 카드: 나는 [관찰]했을 때 [느낌]했어요. 나에게 [욕구]가 중요해서요. [부탁]해줄 수 있을까요? — 보내기는 항상 선택. 자동 전송 없음
  • 받는 사람은 연락처에서 검색해서 고른다. 문장만 만들고 끝나는 게 아니라 실제로 그 사람에게 갈 수 있어야 실효성이 있다. 받는 사람을 고르기 전에는 보내기 버튼이 비활성화된다.

연락처 접근 동의 화면

보낼 문장 탭에 처음 진입할 때 뜬다. 매번 묻지 않고 최초 1회만.

  • 문구: "이 문장을 보내려면 연락처 검색이 필요해요" + "받는 사람을 고를 때만 사용해요. 그 외의 용도로는 쓰지 않아요."
  • 사용 범위 명시 3줄: 사용 범위(이름 검색 결과만 표시) · 저장 여부(저장 안 함) · 공유 여부(외부 전송·공유 안 함)
  • 버튼: 허용하고 검색하기 / 허용하지 않고 계속하기

거부해도 기능이 막히지 않는다. 허용 안 함을 선택하면 검색 UI 대신 이름 입력창 + 복사하기로 대체된다 — 문장을 복사해 사용자가 직접 문자·메신저에 붙여넣는다. 권한 거부가 곧 기능 차단이 되지 않도록 설계한다 (이것도 강요 금지 원칙의 연장).

데이터 분리 — 완전 분리 + 통계만 다리

  • 원문·갈등 서사는 에피소드·챕터에 절대 들어가지 않는다. 재료 성격이 다르다 — 상상은 내가 만든 장면, 갈등 기록엔 실존하는 상대가 등장한다. 서재는 다시 읽고 싶은 장면이어야지, 다시 보고 싶지 않은 순간이 섞이면 안 된다
  • 상대방 이름 등 식별 정보는 저장하지 않는다 ("그 사람"으로만 지칭)
  • 단, 욕구 통계만 선택적으로 합산 가능 — 아침 카드 쪽 욕구 각주와 숫자로만 섞인다 ("이번 달 자주 찾은 욕구: 연결 · 예측 가능성"). 서사는 절대 안 섞는다

안전 경로 — 필수, 협상 불가

자해·폭력이 언급되면 6단계 프로세스를 즉시 중단하고 사람에게 연결하는 화면으로 전환한다. 이 경로는 선택 사항이 아니다.

전환 화면에는 다음 세 연락처를 안내한다 (2026-07-31 기준 확인, 한국).

  • 자살예방상담전화 109 — 24시간, 전국 (2024년 1월 1일부로 옛 1393이 109로 통합됨. 1393은 더 이상 사용하지 않는다)
  • 정신건강 위기상담전화 1577-0199 — 24시간
  • 112 — 즉시 위험이 있는 상황

전환 후에는 정리·조언·되비추기를 하지 않는다. 사람에게 연결하는 경로만 제시한다. 서비스가 다른 국가에 배포되면 지역별 리소스를 별도로 확인해야 한다 — 번호는 시간이 지나면 바뀔 수 있으므로 출시 전 재확인 필수.

4-5. LLM Wiki — 3층 구조

층 내용 갱신 주입
L0 정본 NVC 4요소, 느낌·욕구 목록(고정 어휘집), 가짜느낌 매핑표, 금지 표현 거의 불변 프롬프트 상주
L1 스타일 실물 카드에서 추출한 생성 규칙 + 씨앗 카드 분기 few-shot + 루브릭
L2 개인 욕구 빈도, 반복 모티프, 인물·장소 사전, 미충족 욕구 추이 매일 append / 주 1회 재요약 요약 압축 후 주입
  • 어휘집은 닫혀 있어야 한다. LLM이 느낌·욕구 단어를 창작하면 주간 통계가 붕괴한다. 생성이 아니라 매핑만 허용.
  • L2는 카드 생성 시 참조하되 직접 인용 금지. "지난주에 외로움을 3번 고르셨죠"는 감시당하는 느낌을 준다. 톤과 계열만 조정한다.
  • L2가 다른 앱이 복제할 수 없는 유일한 자산이다.

넣고 싶었지만 뺀 것

  • 느낌·욕구 전체 목록 멀티셀렉 → 기상 직후 인지부하로 90초가 붕괴. LLM 추출 후 확인으로 대체.
  • 카드에 욕구 이름 노출 → 앵커링. 사용자가 자기 욕구가 아니라 카드의 욕구를 고르게 된다. 욕구 계열은 내부 태그로만.
  • 관찰·부탁 단계 → 주말 확장 세션으로 이관.

⑤ 성공 기준

"좋아요" 말고 행동으로 관찰한다.

지표 목표 무엇을 증명하나
엮인 챕터 48시간 내 재열람률 ≥ 40% 산출물이 진짜 갖고 싶은 것인가
책으로 엮기 사용률 측정 후 기준 설정 에피소드가 진짜 자서전으로 이어지는가
챕터·에피소드 저장·공유 발생률 측정 후 기준 설정 작품으로 인식되는가
문장 수정 발생률 관찰 자기 작품으로 여기는가 + 문체 학습 신호량
다음 주 월요일 세션 복귀율 ≥ 60% 루틴이 되는가
느낌 칩 교정률 20~40% 0%면 아무도 안 읽는 것, 60%↑면 LLM 추출 품질 실패
발화 길이 중앙값 ≥ 25초 카드가 상상을 여는가
세션 완주율 ≥ 70% 중간에 빠져나가지 않는가
알람 끈 뒤 카드를 뽑는 비율 ≥ 50% 권유가 통하는가 — 알람 앱으로서의 핵심 지표
나중에 할게요 후 당일 재진입률 관찰 미룬 사람이 돌아오는가

부록. 실물 카드 3장에서 추출한 문장 문법

카드 표면적으로 묻는 것 실제로 심어놓은 전제
"사랑하는 사람에게 진심으로 바라는 것은 무엇인가요?" 무엇을 바라는가 ①사랑하는 사람이 있다 ②바라는 게 있다 ③진심인 층과 아닌 층이 나뉜다
"더 많고, 더 좋고 또는 다른 무언가를 찾는 것을 멈추면 어떻게 될까요?" 멈추면 어떻게 되는가 ①당신은 지금 찾고 있다 ②그건 멈출 수 있다
"어떤 이의 지속적인 사랑이 당신과 함께하고 있나요?" 누구의 사랑인가 ①그런 사랑이 존재한다 ②지금 함께 있다

카드가 하는 일은 질문이 아니라 전제 배달이다. 사용자는 답을 만드는 게 아니라 심어진 전제가 참인지 확인하려고 자기 기억을 뒤진다. 그 뒤지는 과정이 곧 상상이다.

공통 문법

  1. 긍정 전제만 심는다 — 없음을 묻지 않고, 있음을 전제하고 위치를 묻는다
  2. 욕구 라벨을 절대 쓰지 않는다 — 욕구가 사는 장면을 묘사한다
  3. 주어를 사람이 아니라 감정에 준다 — "누가 널 사랑하니"가 아니라 "어떤 이의 사랑이 함께하고 있나요". 사람 이름 대신 장면이 떠오른다
  4. 예/아니오로 닫히지 않는다. 정답·방향 유도 없음
  5. 2인칭 · 현재시제 · 한 질문에 한 축 · 15~35자 · 2~3행 줄바꿈으로 호흡
  6. 어미는 의문형이 기본이되 명령형(~해보세요, ~말해 보세요)도 자연스럽게 섞어 쓸 수 있다 (실물 감사카드 20장에서 확인, reference-gratitude-deck-40q.md 참고)

질문 유형 C(장면확장·감각형)의 실물 근거 — 감사카드에서 확인된 두 문장이 원형이다.

  • "내 몸의 어떤 부분을 당연하게 생각하나요?"
  • "감사하는 마음이 들 때 몸에서 어떻게 느껴지나요?" 몸 감각으로 여는 질문은 90초 세션에서 발화량을 늘리는 데 특히 유효할 것으로 보인다 (아직 실측 전).
