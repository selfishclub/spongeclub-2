# 1주차 — 나만의 OS 만들기 🛠️

> 미션을 진행하며 **과정과 결과물**을 기록해주세요. (다 못 채워도 OK, 한 것 위주로!)
## 🎯 미션 1. 내 OS 재료 찾기
> 인터뷰 스킬(아이데이션)로 "내 삶에 필요한 게 뭔지" 찾기

- **과정 (어떻게 찾았나):**
  클로드의 인터뷰 스킬로 5스텝 인터뷰를 진행했다.
  하루 중 시간을 많이 쓰는 일 → 수업 준비와 집안일 두 가지가 나왔고,
  그중 "할 때마다 귀찮은 것"을 좁혀보니 집안일, 그중에서도
  **장보기·식단 정하기**가 걸렸다. 수업 준비는 이미 내 방식이
  잡혀 있어서, OS가 도울 영역은 '일'이 아니라 '삶' 쪽으로 정해졌다.

- **결과:**
  🟡 내 OS 재료 카드
  · 영역: 삶 (집안일 — 장보기·식단)
  · 걸리는 지점: 매일 저녁 "오늘 뭐 먹지"를 0부터 다시 고민
  · 지금은: 그날그날 메뉴를 즉석에서 고민, 장보기도 그때그때
  · OS가 된다면: 일주일치 식단을 미리 짜주고 장보기 목록까지 자동으로
  · 한 문장: "일요일에 한 번 정하면, '뭐 먹지' 고민 없이 일주일이 알아서 굴러간다"

- **느낀 점:**
  처음엔 딱히 불편한 게 없다고 생각했는데, 인터뷰로 하루를
  들여다보니 매일 반복되는 작은 고민이 바로 OS의 재료였다.
  거창한 자동화가 아니라 "매일 저녁의 고민 하나를 없애는 것"부터
  시작해도 된다는 걸 알았다.

## 🧩 미션 2. 내 OS 기획
> 인터뷰 결과 + 세션 내용(흐민·배짱·키노) 활용해 기획

- **기획 내용:**
  **우리 집 식단 OS** — 3단계 기획
  - 1단계 (이번 주): 가족 구성(70대 여성 1, 50대 부부, 20대 남성 — 4인)과
    취향을 클로드에 알려두고, "이번 주 식단 짜줘" 한마디로
    **일주일 저녁 식단표 + 장보기 목록**이 한 번에 나오는 것
  - 2단계: 냉장고 남은 재료 소진 반영, 지난주 메뉴와 겹치지 않게 기억
  - 3단계: 매주 일요일 자동으로 식단이 올라오고, 장보기 목록은
    주문 앱에 넣기 좋은 형태로 정리되는 전체 OS

  영양 설계 원칙: 단백질(고기·생선·콩)을 매일 바꿔 배치, 생선 주 2회,
  채소 반찬 곁들임. 70대 어르신 기준으로 튀김·강한 매운맛 제외.

- **막혔던 점 / 어떻게 풀었나:**
  처음엔 "식단 짜기"와 "장보기"를 별개 기능으로 생각했는데,
  기획하다 보니 식단이 정해지면 장보기 목록은 저절로 나오는
  **하나의 흐름**이라는 걸 깨달았다. 기능을 늘리는 대신
  흐름 하나를 제대로 잇는 걸로 방향을 잡았다.

## ⚙️ 미션 3. 내 OS 구현
> 실제로 만들어본 것 (클로드코드 '채널' 기능 활용 OK)

- **결과물:**
  1단계를 실제로 실행 — 가족 구성과 조건을 입력하고
  **이번 주 월~일 저녁 식단표 + 카테고리별 장보기 목록**
  (정육/수산, 채소, 기타, 양념 확인)을 대화 한 번으로 뽑았다.
  다음 주부터는 "지난주엔 ○○ 먹었어" 한 줄만 추가하면
  겹치지 않는 새 식단이 나오는 방식으로 운영 예정.

- **링크 / 스크린샷:** (이미지는 `이미지첨부/` 폴더에)
  → 클로드 대화에서 식단표·장보기 목록 화면 캡처해서 첨부
